# 起點時限測試寫死半秒隨機器快慢紅

## 症狀

推送前全套第 2 片紅一條:「起點那側每篇讀 0.2 秒、上限 0.5 秒……」,訊息是 `起點讀了 0 篇、花 0.6 秒`。單獨跑也紅;拿改動前的主線版本單獨跑,3 次 3 次紅,跟筆記格子第 2 步的改動無關。

## 根因

量過:不慢讀、上限放寬時,走到起點那側第一次讀要 1.03 秒(頂端讀 19 篇加 git 呼叫),整支 1.77 秒。測試把上限寫死 0.5 秒,頂端那側就把時間用完,起點那側在讀第一篇之前就逾時,斷言裡「起點至少讀了一篇」不成立。機器快的時候走到起點不到 0.5 秒,所以以前大多綠、並行重負載才偶發紅。

## 修法(已做)

同一支測試先跑一次不慢讀、上限 60 秒的版本,量出走到起點第一次讀的時間,上限設成那個時間加 0.5 秒;耗時斷言改成小於上限加 2 秒。翻紅釘照舊成立:起點那行拿掉截止時間 → 起點 16 篇全讀完、花 5.1 秒 → 紅(2026-10-02 實跑)。

殘留:量測那一趟跟正式那一趟之間機器忽然變慢,仍可能偶發紅。
