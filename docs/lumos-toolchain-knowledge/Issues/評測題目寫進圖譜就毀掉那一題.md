# 評測題目寫進圖譜就毀掉那一題


## 怎麼發生的

這套多詞評測的兩臂是「整串當片語查」對「拆成各詞查」。後者只在**前者全庫零命中**時才啟動。所以只要有任何一篇筆記逐字出現那串查詢，前者就有命中，後者不啟動，兩臂結果一模一樣——那一題從此測不到任何東西，而且**不會有任何錯誤訊息**，它會安靜地印出兩個相同的數字。

2026-09-15 查出來的實況：

- 一題是我當天寫量測紀錄時逐字引了查詢造成的，候選當場從 450 掉到 1。
- **兩題是被那套評測自己的設計文件寫進去的**——那篇的結果表格逐字列了每一題的查詢。從那天起那兩題就壞了，而 2026-08-03 的基線數字是在寫進去之前跑的，所以基線沒事、之後每一次重跑都是壞的。
- 當時重跑的輸出還把這兩題列進「回退了還是一篇都撈不到，要看分詞或同義詞」——**歸錯因了**，真因是題目被污染。

## 為什麼會一直發生

寫筆記的人在做對的事：把題目記下來讓別人看得懂。**沒有人會想到「寫下來」本身就是破壞**，因為在一般的評測裡，題庫跟語料是兩回事；這裡它們是同一堆檔案。

## 處置

- **當下**：三題都改成用斜線分隔的寫法（像「圖譜／同步／閘」），十題重驗全乾淨。
- **規矩**：查詢字面只存在版控的題庫檔裡（那些檔在治理目錄、不在圖譜語料內）。筆記要提到某一題就用分隔符寫，不要留下整串比得到的片語。
- **要有機械守衛**：光靠規矩會再犯——寫的人根本不知道有這條規矩。要一支測試，把題庫裡每一題的查詢拿去掃整個圖譜，掃到就翻紅。REVISIT:2026-09-22 確認守衛已經加上並且拆掉它會真的翻紅。
