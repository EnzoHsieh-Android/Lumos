# 評測題目寫進圖譜就毀掉那一題


## 怎麼發生的

這套多詞評測的兩臂是「整串當片語查」對「拆成各詞查」。後者只在**前者全庫零命中**時才啟動。所以只要有任何一篇筆記逐字出現那串查詢，前者就有命中，後者不啟動，兩臂結果一模一樣——那一題從此測不到任何東西，而且**不會有任何錯誤訊息**，它會安靜地印出兩個相同的數字。

2026-09-15 查出來的實況：

- 一題是我當天寫量測紀錄時逐字引了查詢造成的，候選當場從 450 掉到 1。
- **兩題是被那套評測自己的設計文件寫進去的**——那篇的結果表格逐字列了每一題的查詢。從那天起那兩題就壞了，而 2026-08-03 的基線數字是在寫進去之前跑的，所以基線沒事、之後每一次重跑都是壞的。
- 當時重跑的輸出還把這兩題列進「回退了還是一篇都撈不到，要看分詞或同義詞」——**歸錯因了**，真因是題目被污染。

## 為什麼會一直發生

寫筆記的人在做對的事：把題目記下來讓別人看得懂。**沒有人會想到「寫下來」本身就是破壞**，因為在一般的評測裡，題庫跟語料是兩回事；這裡它們是同一堆檔案。

## ★2026-09-16 又犯一次,而且守衛擋不到這種★

要從真實查詢裡挑題補進題庫，一驗發現十九個候選裡**有五個「片語查得到」**。追下去，其中**四個的污染源是我前一小時自己寫的那篇量測紀錄**——我把那些查詢當例子逐字列了進去。距離我自己寫下「查詢字面只留在題庫檔裡」那條規矩不到一小時。

**★守衛為什麼沒擋★**：那支測試掃的是「題庫裡現有的題」。而我寫量測紀錄時引用的是**還沒進題庫的候選題**——它們不在守衛的掃描範圍內。等到要用的時候才發現已經被自己毀掉。

處置：那四題改成斜線分隔就救回來了（第五個的污染源是更早的計劃節點，那題直接不選）。

**這說明一件事：規矩寫下來不夠，而且現有守衛的涵蓋範圍比想像的窄。** 真正安全的做法只有一條——**寫任何量測紀錄時，查詢一律用分隔符寫**，不去區分「這題進題庫了沒」。

## ★2026-09-16 第三次:詞層級的污染,守衛結構上擋不到★

換完壞題跑新基線，弱證據旗標又響：計分視窗裡有一筆沒標過，**又是我一小時前自己寫的量測紀錄**。同一天內第三次（前兩次一次是片語寫進筆記、一次是候選題被寫進筆記）。

**這次跟前兩次不同，前兩次是我沒守規矩，這次守了也沒用**：

- 那篇筆記**沒有**逐字寫出任何查詢片語（我已經改用斜線分隔）。
- 它只是因為**在分析那道題目**，正文裡自然出現了那幾個詞，於是被拆詞那一臂撈進前五名。

**片語層級的污染守得住（有測試），詞層級的守不住。** 而且結構上難守：量測紀錄本來就要討論那些查詢在問什麼，不可能不提到那些詞。

### 目前的處置只能是事後補救

弱證據旗標**有接住**——它印出「計分視窗裡有 N 筆沒標過、分數是被低估的下限、不得拿來判退步」，逼人先補標。三次都是它擋下來的。

### 想得到但還沒做的結構性解法

- **把評測相關的筆記整個排除在語料之外**（例如某個目錄或某個標籤）。代價：那些筆記也是圖譜的一部分，排除等於承認語料有個洞，而且要有人維護排除清單。
- **量測紀錄不進圖譜，只留在治理目錄**。代價：違反「脈絡寫回圖譜」的家規，而且那些結論確實該被檢索得到。
- **接受它，靠弱證據旗標每次擋一下、補標一次**。代價：每跑一次基線就要補標一兩筆，而且補的都是自己寫的筆記。

三條都有代價，**目前走第三條**（被動補救）。REVISIT:2026-11-16 若補標次數變成每次都有，就該正面處理前兩條。

## 處置

- **當下**：三題都改成用斜線分隔的寫法（像「圖譜／同步／閘」），十題重驗全乾淨。
- **規矩**：查詢字面只存在版控的題庫檔裡（那些檔在治理目錄、不在圖譜語料內）。筆記要提到某一題就用分隔符寫，不要留下整串比得到的片語。
- **要有機械守衛**：光靠規矩會再犯——寫的人根本不知道有這條規矩。要一支測試，把題庫裡每一題的查詢拿去掃整個圖譜，掃到就翻紅。REVISIT:2026-09-22 確認守衛已經加上並且拆掉它會真的翻紅。
