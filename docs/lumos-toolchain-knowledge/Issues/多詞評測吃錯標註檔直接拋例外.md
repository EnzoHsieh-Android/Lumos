# 多詞評測吃錯標註檔直接拋例外


## 症狀

跑多詞評測時把標註檔指到含各評審意見的那份（同一個目錄裡兩份標註檔長得很像），腳本印完兩行標題就掛掉，錯誤是拿字典去跟數字比大小。訊息裡沒有任何一個字提到「你檔案拿錯了」。

## 為什麼在意

那支儀器一個多月沒人跑，接手的人分不出兩份標註檔誰是誰——名字只差一個字，而且看起來比較「完整」的那份才是錯的。踩到的人會先去懷疑儀器壞了或語料有問題，而不是懷疑自己傳錯參數。2026-09-15 我就是這樣先繞了一趟。

## 修法方向（還沒做）

讀進標註檔之後先看一筆值的型別：是字典就直接說「這份是含各評審意見的格式，本工具要扁平那份，請改指到扁平檔」，然後正常退出，不要拋例外。

或者乾脆讓它兩種格式都吃：看到字典就取最終分那個欄位。

## 邊界

只影響這支獨立的多詞評測工具，主評測不受影響（那支自己有標註檔載入邏輯）。
