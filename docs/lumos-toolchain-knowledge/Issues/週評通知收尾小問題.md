# 週評通知收尾小問題

> 白話:週評改成只在同一題連續沒過或通過率顯著下降時才通知之後,審查破例多跑的第四輪還點出兩個小問題,都不會讓通知漏發(事故週照樣通知),所以先放行、在這裡接著修。修的時候當成一個小改動,自己走一次審查。

## 要修的

- **事故那批的 log 記成「無結果」**:探針因儀器事故結束時,主程式把總結行改成「儀器例外: …;整批不能下結論。 0/8 個情境 …」,總結行不在行首,自主迴圈的 grep 抓不到。有判定行時事故週照樣通知(訊息由探針組好);只有 log 那行變「無結果」,而連判定行都沒印出來的極窄情況下舊規則退路也不送。修法方向:讓總結行在事故時仍以 p/n 開頭(儀器例外前綴移到後面,符合 summarize_results 說明的「第一行固定以 p/n 開頭」),或 grep 改成容許那段前綴;並補一組事故輸出的測試。
- **「同一週重跑只留最後一列」跟行為不一致**:最後一列是事故列時,篩選先跳過事故列、沒記下這週,較早那一列就被當成這週收進基準。要嘛改程式讓整週不算,要嘛改說明寫成「只留最後一列可用的」;兩種都說得通,選一種並補測試釘住。

## 什麼條件算修好

- 兩條都有對應的改動與一支拿掉修補就會紅的測試。
