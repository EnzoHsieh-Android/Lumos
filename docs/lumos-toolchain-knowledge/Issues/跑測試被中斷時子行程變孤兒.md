# 跑測試被中斷時子行程變孤兒

白話:跑測試跑到一半被使用者中斷時,測試本身還在背景繼續跑,而它用的暫存資料夾已經被刪了。修正關卡的殘骸清理只清隔離工作樹,不清這種孤兒行程(見 [[Systems/代碼審修正關卡]])。來源 [[Projects/代碼審修正關卡第0步_計劃]]〈範圍〉不做。
