# 引句錨定只驗前綴_後半可編造

> 白話:審查席的引句要能在凍結審材裡找到原文,這是「不採信編造」的機械保證。**但抽取器只取第一個閉引號之前的內容,後面寫什麼完全不看**——所以只要前綴是真的,後半可以隨便編,照樣判過。

## 現象(2026-09-06 實測)

在審材裡放這句:`合法前綴文字至少十個字,後面接的是別的東西。`
席報告寫:

```
引句:「合法前綴文字至少十個字」編造後半根本不在審材裡」
```

`lumos quote-check` 回 **✅ 全數錨定**。抽取止於第一個 `」`,拿到的是 `合法前綴文字至少十個字`,那段確實在審材裡,於是判過;`」編造後半根本不在審材裡」` 從頭到尾沒被看過。

同型巢狀是同一個病的另一種外觀:`「甲「乙」丙」` 只抽到 `甲「乙`,前綴錨得到就過,`丙` 沒被驗。

## 為什麼這是逃逸口不是小瑕疵

引句錨定是收貨三道裡唯一擋「編造證據」的那一道。它現在的保證其實只有「**開頭那段是真的**」,而不是「這句話是真的」。一個想矇混的席位不必做任何複雜的事,把真句子當開頭、後面接自己想講的即可。

★同一支函式的註解記載曾經修過另一種括號組合的同一個洞★(外「」內『』會截斷),證明這個病灶被看見過,但只補了其中一種外觀。

## 為什麼沒有當場修掉(2026-09-06 撤回一次修法)

我先做了「抽出的引句若有沒配對的同型引號就判格式錯」,代碼審 r1 外家席當場打穿:

1. **沒有補起洞**——不用巢狀,把編造放在第一個閉引號之後照樣過(上面那個實測就是它給的)。
2. **打壞既有卷證**——對帳本裡可讀的 613 組報告與快照重放,**148 組(24%)** 會從「全數錨定」變成判錯;而處置閘會把它算進失敗,歷史迴圈回放會轉紅。

所以撤回。**半吊子的修法比不修更糟:它給人「已經補起來了」的錯覺,同時把四分之一的歷史證據判成無效。**

## 修的時候要一起決定的事

- **抽取語意**:是「第一個開引號到最後一個閉引號」,還是「引句必須自成一行、後面不得有其他內容」?前者會誤傷「引句後面接註記」的既有寫法(本 repo 自己就有),後者要改的是紀律不是程式。
- **回溯性**:新判準對既有卷證要不要生效?24% 會轉紅,而那些迴圈當時是照當時的規矩過的。★需要一個「向前生效、不追溯」的設計★,而回放凍結閉包裡的舊判定該怎麼處理要一起想。
- **下游一致**:處置閘會把格式錯算進失敗,嚴重度對帳不讀它,兩邊語意不一致。

## ★真的要修的人必看:兩個結構性前提★(2026-09-06 代碼審 r1 兩席各自抓到)

**一、改判準必須同時推進回放引擎版本。** 回放的黃金抽查靠比對 `_REPLAY_ENGINE_REV` 決定要不要用現在的程式碼對凍結閉包重算:版本沒變就重算,版本變了才視為「制度已演進、跳過重算」。我第一版修法改了判定行為卻沒推版本,**通才席實測**:掃過帳本 665 組已記帳的報告與快照配對,114 組判定翻轉;挑一個已凍結黃金判定的迴圈直接跑回放,現場印出「⛔ 邏輯漂移:同一份凍結輸入重算判定不同」並 exit 1。也就是說那批一推上去,下一次週跑抽查會對至少 114 個放行過的舊迴圈發假警報——**而那不是漂移,是規則升級**。

**二、判法不能把兩件事混在同一條判準裡。** 我用的是「抽出的內容裡同型開閉括號數是否相等」,通才席指出這其實混了兩件事:①內容裡出現過同型開括號 → 確實等於被截斷,結構上不會假警報;②內容裡另一種括號的開閉數不等 → 內容合法但恰好含孤立符號時就誤判。**真實既有卷證裡已經發生**:有一份報告引的是這支抽取器自己的舊正則,程式碼字面就含四種括號字元,那是規則語法不是巢狀引號——修法前判過,修法後被判格式錯。它掃過所有帶引句的既有席報告,修法前後翻轉的共 193 條,逐一核對的樣本裡多數是真巢狀(該攔),但那一條是明確誤傷。

**三、還有一種更容易無意寫出來的觸發方式。** 引句裡只要有一個「落單、沒有配對開括號」的同型收尾符號,抽取一樣在那裡截斷,而抽到的前綴裡開閉數是 0 比 0(平衡),我的守衛完全看不出來,後半照樣可以編造。通才席實測構造過。

**四、抽取器會把理由散文裡的示範引句也當成真引句。** 本輪外家席在說明繞法時,理由欄裡寫了一行示範用的引句格式,抽取器照樣把它抓出來當引句去錨定,於是那份合規報告被判「有一句錨不到」。**要寫「引句長怎樣」的例子,得避開那個標籤**——這件事今天沒有任何地方寫著。

## 現況(誠實記)

**這個洞今天是開著的。** 範本有教席位「引句內不要再包同型括號」,但那是自律不是機械;而後半編造那種形態,範本連提都沒提。

REVISIT:2026-10-06 這條要嘛設計出「向前生效」的修法並走設計審,要嘛明文承認「引句錨定只保證開頭那段是真的」並把這句話寫進所有講收貨三道的地方(現在那些地方都在暗示它保證整句)。
