# 探針設定指紋收尾小問題

> 白話:探針每場記下「實際載入了什麼設定」的指紋之後,最後一輪審查還點出幾個小問題,都只在 Claude Code 改輸出格式、或測試再嚴一點時才有差,不影響現在的判分與統計,所以先放行、在這裡接著修。修的時候當成一個小改動,自己走一次審查。

## 要修的(程式)

- **清單欄位的元素格式不對會被靜默丟掉**:外掛清單的元素不是物件(例如變成字串)時整個被濾掉,指紋跟沒有外掛一樣,`bad_fields` 也不記;skill、MCP 伺服器的元素是物件卻沒有 name 時一律算成空字串。修法方向:元素層也記進 `bad_fields`(例如 `plugins[]`),沒有 name 的物件用穩定的替代表示。
- **主函式裡兩個「儀器例外」結果沒帶 `env_fp` 欄位**:不影響統計(這兩種結果本來就不算分),但同一種結果有兩種欄位形狀;補成跟其他返回點一樣的 null 加原因。
- **「取不到」用了兩種詞**:既有結果用 `"unknown"`,指紋計數用 `"null"`;統一成一種(改動要顧到已寫進歷史的列)。

## 要修的(測試)

- **清單排序沒有測試守**:同一組外掛或 skill 換順序,指紋要不變;現在把排序拿掉測試照綠。
- **MCP 伺服器只取名字沒有測試守**:同一個伺服器的連線狀態從 connected 變 failed,指紋要不變。
- **兩個提早返回點的 `env_fp` 欄位沒有測試守**。

## 什麼條件算修好

- 上面每一條都有對應的改動;程式與測試的改動各附一支拿掉修補就會紅的測試。
