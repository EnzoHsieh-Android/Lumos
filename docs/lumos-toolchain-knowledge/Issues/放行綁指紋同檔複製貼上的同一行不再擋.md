# 放行綁指紋同檔複製貼上的同一行不再擋

## 症狀

新增告警閘擋下一條告警,作者用 `lumos lint-waive <指紋> --note` 放行之後,同一支檔裡再新加一模一樣的一行(縮排也相同),推送時不會再列出、也不用再寫理由。工具本身的告警與之後的行內忽略註解告警都一樣。

## 根因

- 指紋 `_lint_new_key` 是「規則+檔名+命中那幾行正規化後的內容」,沒有出現次序。
- `_lint_new_diff_claims` 有照次數算新增幾條,但 `_lint_new_tools` 最後用「指紋在不在放行檔」過濾,放行紀錄不記放行了幾次。

## 現在怎麼繞

審查時看 diff 裡同一行有沒有重複出現;放行理由寫明涵蓋幾處。

## 什麼條件算修好

放行紀錄記下放行當時這個指紋在那支檔出現幾次,推送時出現次數多於記錄的次數就把多出來的列成新增;有一支測試覆蓋「放行一次、再貼一行、要再擋」。
