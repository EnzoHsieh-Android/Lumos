# 標註寫回把評審名字寫死


## 問題

把雙評審結果寫進題庫的那一步，兩席的欄位名是**寫死**的：一席固定叫 claude，另一席固定叫 gemini。實際上外家席早就換人了（2026-08-23 裁定改用另一家），寫回的程式沒跟著改。

實測（2026-09-15 數）：題庫裡 814 筆標註帶著 gemini 這個欄位，其中 **252 筆是當天寫進去的**——而當天的兩席評審都不是 Gemini。另有 423 筆帶的是 codex 欄位（更早的路徑寫的），所以連形狀都不一致。

## 為什麼在意

分數本身（最終分）沒受影響，受影響的是**這筆分數是誰給的**。

而「誰給的」正是這條管線的規則在依賴的東西：抽驗一致樣本時規定抽驗者不得是兩席評審之一，人裁時規定裁決者不得是任何一席評審本身。**記錯來源，這兩條規則就檢查不出違規**——看紀錄的人會以為評審是 Gemini，於是放心讓真正評過的那一席去抽驗。

## 修法方向（還沒做）

寫回時把兩席的名字當參數傳進去，預設留空就報錯不給寫；欄位名改成中性的（第一席／第二席），另存一欄記實際是誰。

舊資料怎麼辦要分開想：直接改寫歷史標註會動到累積數月的資產，應該只補一份「哪段期間的 gemini 欄其實是誰」的對照，不動原檔。
