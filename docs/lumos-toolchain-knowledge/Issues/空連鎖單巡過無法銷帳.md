# 空連鎖單巡過無法銷帳

- REVISIT:2026-09-12 房務批開工:rel-cascade 巡過動詞(修法本單已寫;Enzo 2026-09-01 委任裁辦)

> 白話:決策翻案會自動開一張「去看看誰還引用舊決策」的待辦單。單如果天生是空的(翻案當下沒人引用),就沒有東西可判——但體檢認「有判定才算看過」,於是**空單會被嘮叨到天荒地老**,嘮叨久了人就學會忽略,正是提醒麻痺型。

## 現場(2026-08-31)

- 票 c-20260829073559-6bd5006c(root=[[Projects/impact鏡頭機械化_計劃]]#d1,8/29 翻案開):**機械驗證零候選**(全圖譜無任何 verified_by/plan_refs 邊指向該計劃),已人工巡過確認空。
- 但帳本只有 header、零 transitions → doctor E4 每天警一次,無任何合法方式銷帳(confirm/prune 都要一條邊;手改帳本違規)。
- 前案 [[Projects/連鎖佇列軟提醒_計劃]] d2 明文裁「零筆=沒看過」語意且**不記分母**——當時樣本都有候選,空票型沒進視野。

FLAG:TECHNICAL
DECISION:修法候選=`rel-cascade` 加一個「巡過」動詞(對空票記一筆 visited 事件;E4 數 transitions 自然清)——與 d2 語意完全相容(嘮叨=偵測「沒看過」,巡過即該閉嘴);約 15 行+測試,走一輪輕審。**回頭條件**:下次房務批;或這行嘮叨開始被人忽略的跡象(又一張空票出現)時升級。在修好前,E4 對此票的警告=已知噪音,判讀時可對照本單。
