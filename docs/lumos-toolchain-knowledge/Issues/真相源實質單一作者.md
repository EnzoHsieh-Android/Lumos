# 真相源實質單一作者

> 白話:圖譜用「團隊的唯一真相來源」的語言在描述自己。實際上它幾乎只有一個作者、一個讀者——而**真正的讀者是 AI,不是人**。

同一人合計 **1,311 / 1,329 = 98.6%**。

## 為什麼值得記一筆

**這不必然是缺陷。** 給 AI 的持久記憶本身就有巨大價值——2026-08-20 的實例:一個新 session 只讀圖譜就還原出整套工具的設計始末,包含每個轉折的替代方案與否決理由,這件事 git log 做不到。

★但「單一真相來源」這個詞承諾的東西更多★:它隱含**多人共讀、彼此校正、決策被他人挑戰**。目前圖譜裡的每一條決策,提出者與唯一讀者是同一人;**沒有任何一筆紀錄顯示有人因為讀了圖譜而反駁過某個決策**(未逐筆查證,若有請補)。

這與 [[Issues/外家席長期缺席仍照跑loop]] 是同一形狀的問題在不同層:**驗證的獨立性缺席**,一個在 AI 審查層,一個在人的層。
