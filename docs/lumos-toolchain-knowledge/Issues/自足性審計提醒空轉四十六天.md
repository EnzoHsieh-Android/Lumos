# 自足性審計提醒空轉四十六天

> 白話:有一道提醒「這個節點該重做自足性審計了」的軟提醒,**響了一萬八千多次,沒有人處理**。它從 2026-07-02 開始響,到今天還在響同一批節點。

## 可數事實(2026-08-20 實測)

- 原始 18,283 筆 / 去重後 7,317 筆,涉及 **42 個節點**、421 個 commit、46 個有紀錄的日子。
- 平均每個節點被念 **170 次以上**;最高的一個被念了 1,003 次(原始計)。
- 曾被警告、之後停止的節點:12/42。★其中 9 個在同一天(2026-07-24)一起停★,形態與「一次批次補戳」相容。
- **到帳本最後一天(2026-08-19)仍有 30 個節點在被念。**

## ★最該記的一條:它是怎麼被發現的★

**不是巡檢抓到、不是任何機制報告的。** 是 2026-08-20 為了一個外部調研任務,順手去 grep 治理帳時看到的。

這條系統的賣點是「機械地發現漂移」。而**「機制本身在空轉」是最該被偵測的漂移**,它靠的是運氣。

## 同一病灶的第三例

- [[Issues/連鎖佇列開了沒人跟完]] — supersede 開的待辦單兩張都是空的;★同樣是「要主動跑才看得到,doctor 不報、pre-push 不提」★。
- 那張單子已經把病灶命名為**路徑問題不是紀律問題**。本單是同一病灶的第三例,而且量級大兩個數量級。
