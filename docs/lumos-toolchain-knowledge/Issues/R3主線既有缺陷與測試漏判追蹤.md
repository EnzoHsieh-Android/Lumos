# R3主線既有缺陷與測試漏判追蹤

## 處理與繞法

本批先修新增額外測試路由的ABA，不順帶重寫跑滿回顧與告警指紋。上述發現仍open，各問題另按固定兩端、同輸入、實際載入及修補／保留控制設計，不以此追蹤篇當放行票。資料與環境只記非敏感證據。

## 算修好的條件

每項有實際固定修前紅、修後綠及至少一個獨立保留案例；錯誤注入須命中目標斷言且還原後綠。涉及告警豁免時要明確選人工重驗或數值機械閘，不假稱已有自動防護；完成的項目逐項連同版Verification，本篇全項結清前維持open。
