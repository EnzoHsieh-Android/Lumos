# 未標候選順序每次跑都不一樣

> 白話:同一個問題問三次,回來的名單一樣,但名次排法不一樣。名單穩、名次不穩。

## 怎麼重現

連續跑三次增量補標的未標清單,把每題的候選順序存下來比對:

```
python3 governance/eval/refresh_labels.py delta --goldset governance/eval/retrieval-goldset.json --repo . --json --out /tmp/dt1
```

把 `dt1` 換成 `dt2`、`dt3` 各跑一次,再比對每題的 `unjudged` 陣列。2026-09-15 實測:成員三次都一樣(240 筆),順序有四題在變。

## 為什麼要緊

- **截前 k 的視窗邊緣會換人**:排在第 k 名附近的候選,這次進窗、下次出窗,於是「這題有沒有未標」可能跟著變。
- **回溯不到**:標註者當初看到什麼順序,事後重跑看不到同一份。
- 而這些順序最終餵給的是★不可逆★的尺切換判定。

## 還沒做的

**根因沒查**。這是做別的事時順手撞到的,只確認現象可重現就先記下來。四題全在編輯面,懷疑是候選產生或同分排序吃到不穩定的迭代順序,但沒有查證,不要把這句當結論。

REVISIT:2026-10-15 查根因;在那之前,凡是新寫「依賴候選順序」的東西都要先自己排一次正規順序,不要假設上游穩定。
