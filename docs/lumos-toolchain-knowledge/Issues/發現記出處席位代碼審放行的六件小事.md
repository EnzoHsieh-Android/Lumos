# 發現記出處席位代碼審放行的六件小事

`code-發現記出處席位` 代碼審第 3 輪(上限輪)只剩 minor,使用者 2026-11-21 裁「附理由放行,另開問題單」。這篇列那幾件,下次改到 `--finding-seat` 或 `gov --stats` 逐席段時一起修。席報告在 `governance/review-reports/code-發現記出處席位/r3-*-sonnet.md`。

## 症狀

1. **帳上時間全壞、又有殘留覆寫時靜默放行**:同一迴圈帳上每一列時間都讀不動、`LUMOS_FINDING_SEAT_SINCE` 推到未來、本筆時間在常數生效日之後——必填被推遲,卻不提醒、不留 `finding-seat-since-overridden` 事件(首筆算不出來,提醒條件 `first >= const` 不成立)。修前這種情況會擋 `finding-seat-badts`。
2. **筆記自相矛盾**:[[Systems/loop-convergence-recording]]〈發現出自哪一席〉那段同一條裡,前半句說「帳上有時間讀不動的列時判不了生效前後,不放行」,後半句說「本筆時間早於生效日就直接不必填,帳上有壞時間的列也不擋」;[[Projects/代碼審發現記出處席位_計劃]]〈做法〉生效日那點與〈依據來源〉也還寫「壞時間不放行」。現況以程式為準:本筆早於生效日時不看壞列。
3. **事件寫成 `auditor=None`**:載體沒帶 `--auditor` 卻帶 `--finding-seat` 被擋時,事件字串是 `auditor=None`;鄰居 `refuted-set-missing` 寫 `auditor=`(用 `auditor or ''`)。只影響治理帳字面值。
4. **席名夾換行時統計是二次方**:`_SEAT_SPLIT_RE` 沒有 DOTALL,席名帶換行時每個「連字號接英文字母」都要掃到換行才失敗;6 萬字元約 5.5 秒。修補前就這樣;正常席名沒有換行。
5. **全形數字輪次記號不去**:`_seat_noise_name` 改成只認 ASCII 數字後,`正確性２-sonnet` 不再併回 `正確性-sonnet`(修前會)。
6. **兩個小一致性**:canary 閘的 `_gate_event_or_warn` 以前只用 `blocked`,這次推遲事件用了 `warned`(要確認 `gov --stats` 的計數口徑沒把它算進擋下);新測試 `t_finding_seat_docs_match_since` 讀 `skills/` 前沒先呼叫 `_need_src`(消費專案沒有這些檔時會紅而不是跳過)。

## 根因

前兩輪修補各自補一個角落,判斷式改寫時沒把「首筆算不出來」那一支併進提醒;文件改了後半句沒刪前半句;刪包裝函式時沒把 `or ''` 搬回呼叫處。第 4、5 件是正規式與數字字元集的取捨。

## 現在怎麼繞

1. 不在 shell 留 `LUMOS_FINDING_SEAT_SINCE`(測試總檔只在測試程序裡設)。
2. 讀筆記時以程式為準。
3–6. 只影響治理帳字面值、統計速度或分列,不影響記帳與任何閘的判定。

## 什麼條件算修好

- 第 1 件:帳上時間全壞加覆寫推遲時,stderr 提醒並留 `finding-seat-since-overridden`(補一條測試,修前紅)。
- 第 2 件:兩篇筆記只剩一種說法,跟 `_finding_seat_required_block` 的判斷順序一致。
- 第 3 件:四處事件改 `_esc_clean(auditor or '')`。
- 第 4 件:切角色改用不回溯的寫法或加 DOTALL,測試加一個帶換行的長席名。
- 第 5 件:判數字改用 `str.isdigit` 一類認 Unicode 數字的寫法,或寫明只認 ASCII。
- 第 6 件:確認 `gov --stats` 計數口徑;新測試讀檔前加 `_need_src`。
