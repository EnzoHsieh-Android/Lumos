# 2026-09-08 iOS 與 Node 補棧：合成樣本測試

> 白話：這篇只證明「照設計寫的 regex 和分流邏輯，在我自己造的小樣本上會動」。它**不**證明真的 iOS 或 Node 專案接得上——那要等第一個真專案。

## 跑了什麼

| 測試 | 斷言 | 驗什麼 |
|---|---|---|
| t_swift_profile_discovery | 7 | XCTest `func test*` 認得；`@Test func`、`@Test("顯示名")`、`@Test` 換行加修飾詞都認得；非 test 前綴裸 func 不收；註解內剝掉；pure 目錄取 AppTests 排除 UITests；behavioral 取 AppUITests |
| t_node_jest_profile_discovery | 7 | `test/it/describe('id')` 含 `.only/.skip`；多字 title 不可綁；註解剝掉；非 `*.test.*`/`*.spec.*` 檔不掃；scaffold 產物命中檔名錨；node-vitest 是同一份設定 |
| t_pitfalls_diff_node_flavor_by_package_json | 4 | 後端 .ts（fastify）附 node 題與 node-idioms；前端 .ts（vue）不附 node 題、仍 vue-idioms；沒 package.json 走舊行為；.swift 附 swift 題與 swift-idioms |
| t_checky_swift_and_typescript_profiles | 4 | symbol_profile 換 swift／typescript 不吐「未知 profile」；存在的符號不吵、幽靈符號被抓 |

重跑指令（任一支）：

    python3 scripts/test_lumos.py -k swift_profile

## 抓到的東西

- **舊 bug**：Check Y 的碼庫掃描表沒有 `.swift`（也沒 `.dart`），Swift／Dart 專案的符號存在性檢查等於整段沒在跑。補表後轉綠。
- **設計修正**：Swift 測試目錄的 behavioral 規則第一版寫錯（suffix 模式會先取到 AppTests），寫測試時才發現，改成 behavioral 只認 `*UITests`。

## 沒驗的

- 真 Xcode 專案的 target 佈局、SwiftPM 的 `Tests/`、Jest 的 `__tests__/` 無後綴檔。
- `xcodebuild -only-testing` 對 Swift Testing suite 的識別子格式。
- SwiftLint SARIF 進 lint.json 後 diff 行號對不對（已知有 uri 絕對路徑的 issue）。
