## 結果與證據

- Python CLI 行為考卷 21 案例全過；既有 t_test_quality_scan_cli 執行入口通過，文件指路、分類單源與入口一致性子集通過。
- 固定掃描器故障兩案都 detected：停用自比辨識、停用來源文字辨識；各自基準綠、對應斷言紅、還原綠，無匯入／語法錯代打。來源 hash、測試身份與完整失敗輸出在 governance/review-reports/test-quality-scan-pilot/faults.json。初次尚未建工具的測試失敗不計入抓錯證據。
- Semgrep CE 1.179.0 在獨立暫存 venv 安裝，官方 wheel hash 核對後執行，未改全域環境或消費專案。Python／Kotlin／Java／Swift XCTest／C# xUnit／JavaScript／TypeScript 的 28 個語法片段：22 verified_for_supported_rules、6 unanalysed，supported_checks_match=true；完整考卷 rc2 是這六條算法重抄未分析，不是把它們算成功。
- 非 Python 的已驗能力只含固定斷言介面自比；Swift Testing 的 #expect 不在支援內。這是語法樣本，不是 Android／iOS app、SDK／裝置、完整框架或真實專案驗證。
- Lumos 三份現有測試檔掃到 1949 個 test_/t_ 宣告，3 個候選，約 6 秒：先前 split 分組與 PID 暫存兩個弱測試重現命中；difficulty 穩定性測試屬合理目的。這是三個候選的人工核對，不是全 repo 人工審查或一般誤報率。

原始證據在 governance/review-reports/test-quality-scan-pilot/：unit.log、ci-entry.log、entry-check.log、doc-pointers.log、doc-single-source.log、doc-entry-agreement.log、doc-table-shape.log、faults.json、corpus.json、lumos-scan.json、manual-dispositions.json。固定考卷輸入與規則來源由報告各自的 SHA 綁定。

- 明示 --check-helper check 後，Lumos 主測試檔 1779 個宣告中，1770 個具有已辨識的斷言，列出 70 個候選；此份是候選定位輸出，不與前面三個已核對項目混算；人工裁決只在審查本次波及的測試時處理相關項目，工具不據此阻擋推送。證據為 lumos-check-helper.json。helper 的條件參數位置由使用者明示，不猜其他專案的 check 名稱語義。
