# 2026-08-30_intake守衛T1-T4落地

驗證 [[Projects/intake守衛_計劃]] d1(三輪達上限攤牌後人裁放行)的 T1-T4 落地。

## 做了什麼

- **T1** 宣告行慣例:`_intake_declared`(剝 fenced 圍欄→行首 fullmatch `preflight-4: ran`;多行=格式壞視同無)+ `_intake_dir_status`(綁迴圈不綁輪;無目錄=scratch 跳過)。templates.md 慣例正本與 SKILL.md 步驟 2 同步。
- **T2** 處置閘 advisory 一行(觀測不進合取不改 rc):非 code 迴圈才看;✓/⚠/跳過三態。
- **T3** `canary record --intake` 選配(照 --report 四行為:讀不到/空檔 rc2、路徑正規化、落 path+sha256;進結局帳互斥 tuple);處置閘③ ★全輪掃★ 重驗 intake sha(r3-F3:intake_path 掛 r1 而判定輪多為 r2+,只掃判定輪=常態空轉)。
- **T4** doctor [I] 段:滾動窗(最近 6 個非 code 迴圈,cutoff=宣告行誕生日 2026-08-30)計宣告行出現率;<5/6 且缺席迴圈帳面有 blocker 輪 → 印「轉硬擋條件已達,去裁」。排程線=daily-governance.sh 補 doctor 每日跑(外家 r3 唯一補件——「doctor 每天跑」此前是未查證的假宣稱)。

## 驗過什麼

- 兩支測試 16 斷言全綠,含兩支翻紅釘:①竄改 r1 的 intake → 閘 FAIL(sha 不符;證全輪掃真的在掃——只掃判定輪就抓不到)②有檔無宣告行 → advisory ⚠ 且 rc 不變。helper 五情境單元驗(正常/圍欄假命中/多行/帶箭頭/無)。
- 冒煙即 dogfood:T2 第一個點名的就是本案自己的迴圈(r1-intake 當時無宣告行 → ⚠;補行後 → ✓)。
- ★落地時撞到並修掉兩個實作級陷阱★:①git 裸日期 `--since=2026-08-30` 把時刻預設成**當下**不是午夜——當天恆空;必帶 T00:00:00(spec 數法同步加註)②T4 窗 cutoff 若用 08-25(intake 慣例日)而非 08-30(宣告行誕生日),首日必觸發且歷史迴圈永不能合規(r3-F5「同向偏誤」的實現,冒煙當場撞)。

## 天花板(誠實)

- 宣告行只證「有宣告」,「ran 但沒跑」機械驗不了——靠席位覆核+revalidate_when 的造假條款。
- T2/T4 蓋不到 panel/light/settle/legacy 舊帳路徑;新迴圈一律處置閘,缺口隨舊帳退場收斂。
