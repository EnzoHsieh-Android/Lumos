# 2026-08-24_固定席降噪A層落地

> 白話:改程式時 hook 推的「必看」清單,一半以上是掛著「守衛面」軟標記、跟誰都隔一跳的樞紐筆記。
> 現在保送只認「改了就壞」的硬合約;軟標記的降到輸出尾端一個標明「守衛面參考」的小節(最多 3 條)。
> 結果:沒見過的那半考卷上,噪音砍一半、人先看到的三行必看率翻四倍、該推的一篇沒少。

## 數字(考卷口徑,轉正輪)

| 尺 | 改前 | 改後 |
|---|---|---|
| 固定席噪音(held / all) | 82 / 96 | **39 / 50** |
| 輸出前 3 名必看命中率(held / train / all) | 0.083 / 0.463 / 0.281 | **0.367 / 0.611 / 0.483** |
| 必看推出(all) | 66/70 | 66/70(棘輪綠) |
| P@8 / nDCG | — | 逐 byte 不變(free 集不動,結構保證+測試釘) |

11 關全過(新增:噪音棘輪 all+held、must held 棘輪)。LANE_N train 掃 2/3/5 不敏感 → 留 3。

## 機制

- 保送:indirect hop≤1 只認 INVARIANT/IRREVERSIBLE;RISK·* 收進 `lane_raw`(★獨立容器,自始不進 results★)。
- lane:R 公式分數、`(-score,hop,node)` 排序、產生端 cap 3(JSON=人讀=hook 同一份,口徑合一→棘輪有效);
  JSON ★獨立頂層鍵 `lane`★(決策 d2:沒學過的讀者結構性安全——diff 聚合/hook free 桶/守衛零改動),條件鍵兩態。
- 消費端 opt-in:hook 新小節(`.get`+空判斷閘含 lane、「另有 N 條未列出」)、人讀小節、
  eval `split_buckets` 唯一分流(free 不含 lane★含 rescued——誠實計噪護欄,考古翻案保留★)、
  `_touched_edit`/`edit_pool` lane 視同 pins 進未標池、`output_top3_must` 母體不含 lane。
- 守門:噪音棘輪(只准降)+must 棘輪 per-split;總開關 0 逃生(逐 byte 舊制,測試釘)。
