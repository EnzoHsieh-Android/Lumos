# 2026-09-13_Flutter補棧合成樣本測試

> 白話：在合成樣本上確認「多認得 Dart 這件事真的接上了」。沒有任何真的 Flutter 專案參與。

## 跑了什麼

| 驗什麼 | 怎麼驗 | 結果 |
|---|---|---|
| 測試掃得到 | 造一支帶 `test('名')`／`testWidgets('名')` 的檔，含註解裡的假測試 | 兩種都認得，註解裡的兩個都剝掉 |
| 符號形狀 | 拿 `_HomePageState`／`CartPage`／`CartPage.build`／`fetchUser` 比對 | 前三個收得到，裸 camelCase 不進候選 |
| 改 Dart 的檔會附題 | 臨時 repo 改一支檔，跑風險掃描要 JSON | 附六題，棧鍵是 dart |
| 畫面題與常駐題分流 | 一支純非同步的檔、一支 widget 檔，**刻意分成兩支** | 非同步那支只亮 `dart-async`；widget 那支亮 `dart-build`＋`dart-list`，不亮平台通道 |
| 只改測試檔不附題 | 只動 `test/` 底下的檔 | 零題 |
| 慣例 skill 派得出去 | 架構對齊鏡頭的輸出 | 帶 `dart-idioms` |
| 觸發字反面詞 | `.then(` 鏈、`ListView(children:)`、直接 `jsonDecode` | 各自亮同一題；中性的一行零觸發 |
| lint 規則代號存不存在 | 18 個寫進設定檔跑一次，**另混一個故意不存在的名字** | 只有那個假的被判不認得 |

**樣本為什麼要分成兩支檔**：同一支檔改寫時，被刪掉的那行也算改動行（這是刻意的設計，純刪除也要觸發）。寫在同一支檔裡的話，上一版的 `await` 會讓非同步題跟著亮，就驗不到「畫面題各自獨立」這件事。
