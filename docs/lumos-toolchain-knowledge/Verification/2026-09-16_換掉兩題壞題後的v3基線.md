# 2026-09-16_換掉兩題壞題後的v3基線


## 為什麼換題

追「兩個詞的查詢比較難把對的排第一」這個現象時發現：**它整個由兩題撐起來**，而那兩題在標註階段就被評審標記過有瑕疵。

| 兩詞題 | 池裡「必看」幾筆 | 第一個對的排第幾 |
|---|---|---|
| 正常的三題 | 3／5／7 | 全部第 1 |
| 被換掉的其中一題 | **1** | 3 |
| 被換掉的另一題 | 4（意思分歧） | 3 |

- 一題：**這個庫根本沒有那份東西**，每篇只有各自一條相關約定。第四方評審與第三席各自獨立指出同一個原因。
- 另一題：查詢詞在這個庫**至少五種意思**（複製檔／簿記檔／已審查候選／檔名字元／欄位），只有一種是查詢要的。

**沒有正確答案存在，排不出來是正常的**——那是題目的問題，不是檢索的問題。

## 換上什麼

兩題都來自真實查詢紀錄，逐題驗過片語查不到，而且**先確認過「這個庫真的有一篇專門在講它」**才收——這一步是被換掉的那兩題教會的。

標註：兩席獨立標 32 筆 → 一致 **75%**（前兩輪 58%、66%）→ 第三席重判 8 筆爭議 → 多數決收 7 → 人裁 1 筆。評審甲獨立回報「兩題的候選池都答得出來，題目本身沒有問題」。

## 過程中第三次撞到自己污染評測

跑基線時弱證據旗標又響，**又是當天稍早自己寫的量測紀錄**擠進計分視窗。跟前兩次不同的是：那篇**沒有**逐字寫出任何查詢片語（已改用斜線分隔），它只是因為在分析那道題目，正文自然出現那幾個詞就被拆詞那一臂撈進前五名。

**片語層級守得住（有測試），詞層級結構上守不住。** 三條可能的解法與代價寫在 [[Issues/評測題目寫進圖譜就毀掉那一題]]，目前走「靠弱證據旗標被動補救」那條。

★三次都是弱證據旗標接住的——那是這一輪唯一每次都沒漏的守衛。★

## 出題判準因此多一條

原本的判準是「來源限真實使用、候選量不超標、每題寫一句代表哪個失效模式」。這次多學到一條：

**★收題之前先確認「這個庫真的有一篇專門在講它」★**——湊得出候選不等於有答案。沒有答案的題目會系統性壓低每一次量測，而且很難事後看出來（分數低會被讀成檢索爛）。
