# 2026-10-16_陌生棧簡報跨模型試跑

本篇只驗證跨供應商編輯審查的流程與原始回覆收存。正式 S3、十場成對評測與 Brief 增益均不在此 pass 範圍。

## 實際觀察

Gemini 3.6 Flash 首次回 503，重試逾時；改用 Gemini 3.5 Flash-Lite 後，先完成不含 Brief 的獨立分析，再於 Brief 審查遇 503 後重試成功。兩份成功回覆與三筆失敗均保留，未將失敗替換成成功紀錄。原始卷證：governance/eval/unfamiliar-stack-brief/trials/2026-10-16-U4-gemini-editorial.json。

模型第一步只收到任務契約與批次函式，沒有答案、修復版或 oracle 主程式；第二步收到前次回答、候選 Brief 與本機 R2 條款。原始要求明示同時執行量上限為 3，兩筆輸入屬正常案例。模型在看 Brief 前即指出未限制並行的缺陷，並保留正常反例；因此本次沒有證明 Brief 的額外召回增益。

編排者在本機重跑 U4 四格：buggy/target 為 1，buggy/normal、fixed/target、fixed/normal 皆為 0。這只能核對本案故障，不代表所有 worker 都會達到同一峰值；同步完成的 worker 不一定重疊。

## 不採信的放行結論

第二步把沒有修復碼當成沒有洩題，未充分分析缺陷位置與答案語意；無遺漏、無誤報的概括也缺逐欄證據。其容量未提供的說法沒有分清 Brief 本文與共用任務已給的數字。因此不採信它作為 S3 通過證明。

後續審查需逐欄引句、區分共用契約與 Brief、新增缺陷位置和答案語意的洩題檢查。同會談先後兩步只供編輯回饋，不充當兩個獨立評測臂。免費額度、帳號計費與模型長期可用性也不在本次驗證範圍；卷證不含 API key。
