# 2026-08-30_席報告圖譜使用一次性盤點

[[Projects/loop數據收集_計劃]] d2 縮案的交付:字串型常設指標被 std r1 五席判死後,改用內容級人工判讀,量「d8(圖譜內容貼進派工詞)之後,審查席的報告有沒有實質用圖譜」。

## 數據(24 份正式樣本;殘留 2 份另計)

| 判定 | 份數 | 比例 |
|---|---|---|
| **實質使用**(節點內容載重於 finding/判斷) | 8(嚴格口徑 6★) | 33%(25%) |
| 表面提及(名到內容沒到) | 4 | 17% |
| 零 | 11 | 46% |
| 拿不準(已列疑義不硬判) | 1 | 4% |

★嚴格口徑:兩份 code 席引的「圖譜節點」是作者自寫的交付驗證筆記——按字面算實質,按精神近於核對被審材料;兩種口徑都記,不挑好看的。

## 三個真訊號

1. **設計審在用圖譜,代碼審幾乎沒在用**:design 型 14 份裡實質 6-8;**code 型 10 份嚴格 0 真使用**(僅有的 2 份都指向作者自寫驗證筆記)。d8 的圖譜鏡頭同步進了 code-loop skill,但 code 席的 finding 不以圖譜他節點知識為據——是「代碼審本性就該看 diff」還是鏡頭沒接好,本盤點不裁因果,列為下次改 code 鏡頭前的必讀基線。
2. **外家席是圖譜的最大用戶**:8 份實質中 4 份出自外家或轉述外家——本週外家屢次否決成立,靠的正是挖出既有裁定(「已裁不做」節點)。圖譜內容對「防重造輪子」的價值在外家席上最實。
3. **字串指標與真使用反相關的實證**:字串口徑前桶 31.2%→後桶 9.5%(外家量),內容口徑後桶實質 25-33%——**貼進派工詞之後席位不需要再引路徑,字串量到的下降恰是機制生效的形狀**。這筆構念效度反證是「不建常設指標」(計劃 d2)的核心證據。

## 誠實天花板

單一編碼員+抽查 3 份(全對);三值判定含判斷成分,帶星 2 份與拿不準 1 份的疑義原文照錄於編碼表(governance/review-reports/graph-usage-stat-std/one-shot-coding.md);「圖譜當搜尋語料」型接觸(召回實驗)歸零/表面的口徑可爭,表已留〔語料〕註記可重切。46% 零不必然是壞事——架構席/資料席的鏡頭本就不需要圖譜。
