## 翻紅釘(寫測試當場翻紅的三個)

| 弄壞什麼 | 抓到的 |
|---|---|
| 粗體 `**severity**: major` | 拒收偵測放過(正則要求字後直接接冒號)→ 加 `(?:\*\*|__)?` |
| 圍欄裡一行 `severity: blocker` | `_report_severities` 數進去、拒收偵測卻不看圍欄 → 兩邊改用同一套 `_visible_lines` |
| 同 commit 連撞三次 blocked | gov 去重鍵 (commit, nodes, gate, kind) 折成 1 → canary/blocked 拿 ts 當第 5 鑑別子 |

## 天花板

- `reported` 只證明「報告裡有幾行獨立 severity 宣告」,不證明每行都是真的 finding;席位把一條拆三行就是 3。
- `--refuted-set` 對 intake 只驗「那一列有這個 id 和 HIT/MISS 字樣」,不驗重現做對了。
- 讀側永遠不印比率;K<5 時它自己會說樣本太少。
