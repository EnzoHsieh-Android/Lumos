# 雲端工作階段開場設定

雲端工作階段一開場就跑 `.claude/hooks/session-start.sh`(由 `.claude/settings.json` 註冊),本機不跑。為什麼要有它、5 支測試各自的原因見 [[Projects/雲端環境跑綠全套測試_計劃]]。

改這支腳本後,在雲端工作階段裡用 `CLAUDE_CODE_REMOTE=true` 直接跑一次確認不報錯,再挑一支建 venv 的測試(`-k t_hook_cmd_uses_running_python`)確認還是綠的。
