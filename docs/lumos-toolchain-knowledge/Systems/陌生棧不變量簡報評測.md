# 陌生棧不變量簡報評測

本系統只處理評測材料的凍結、開跑前資格與已評分 receipt 的匯總。它不會自動產生 Invariant Brief、不呼叫模型，也不能替 code-loop 放行。

U2 的 `governance/eval/unfamiliar-stack-brief/cases/U2/buggy.dart` 與 `governance/eval/unfamiliar-stack-brief/cases/U2/fixed.dart` 也由本節點管：這是合成 owner／subscription 生命週期案例，不是真實 Flutter 畫面或插件資格。現有 home 機檢副檔名未涵蓋 Dart，人工歸屬仍須寫明；本階段不為評測擴張正式守衛。

評分必須先由外部答案核對，儀器不能自證 finding 為真；獨立測試經專案 runner 轉接是為了沿用既有驗收入口，不另建一套閘門。

事前擴大線是：Brief 臂至少多命中兩案，假陽性最多比 control 多一條，且正常反例誤傷不得變多。任一場無效、不是陌生棧、缺臂或重複臂，結果只能是 `incomplete`。

派工清單必須先經獨立洩題審；路徑角色是評測者宣告，不是內容安全證明。只靠檔名排除答案曾放過 fixed 與不在凍結集合的材料，因此正式十場採逐案共用清單與 Brief 單一增量；資格 manifest 本身不能直接開跑。

評分只收實際布林與合法計量值；JSON 字串 false 不等於布林 false。無效列保留原始 receipt，不參與計數，也不能放行擴大。
