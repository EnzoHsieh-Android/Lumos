# 代理繞閘問人

> 白話:代理要繞過 Lumos 的閘(推送或提交帶 `--no-verify`、提交帶 `-n`、改掉或拆掉掛鉤目錄、設 `LUMOS_SKIP_*`)時,Claude Code 執行那條 Bash 之前先跳確認框問人。只是在引號或 heredoc 裡提到這些字樣、或在拋棄式實驗 repo 裡做實驗,不問。

## 管什麼

- `scripts/hooks/claude/bypass-ask-hook.py`:讀一次 stdin、在記事件之外先做便宜的預篩;過了預篩才進共用的存活事件包裝,解析指令(剝 heredoc、換掉指令替換、`shlex` 切段、任何不在引號裡的 git 詞開始一條 git 指令),判命中與拋棄式,命中回 `permissionDecision: "ask"`。
- 註冊、安裝名單、防護狀態那一列、錨點與工具自裝檔名單在 [[Systems/lumos-cli-lifecycle]] 那邊。

## 不管什麼

- 不擋、不改指令、不記問了幾次(存活事件只記活著沒)。
- 不管 Codex(Codex 的 Bash 前事件回覆形狀不同,適配另見計劃 REVISIT)。
- 不防有心改寫:變數拼接、別名(shell 與 git 的)、腳本、`bash -c`、`eval`、餵給 shell 的 heredoc、直接改 `.git/config`、不經 `git push` 的送出、用 Edit/Write 工具改設定都攔不到。指令替換(`$(…)`、反引號,含雙引號裡的反引號)與程序替換裡的指令會抽出來另外判,但目錄一律當判不出、不給拋棄式豁免;bash 在反引號裡會先把「反斜線接反斜線、反斜線接反引號」還原掉一個反斜線再解析,這一步沒做,所以靠它藏起來的寫法(例如反引號裡用跳脫反引號再包一層)攔不到,引號內外都一樣;反斜線接錢字號遮罩後仍是錢字號,攔得到。
- 自己寫一套切段器,不重用收工圖譜同步檢查那支掛鉤([[Systems/graph-sync-coverage]])裡的切段函式:那支不追蹤引號與 heredoc、作者自註「Quote-aware 不嚴格」,而且檔名帶連字號、各自獨立安裝,不能互相 import。
