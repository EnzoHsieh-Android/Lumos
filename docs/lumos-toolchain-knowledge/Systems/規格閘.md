# 規格閘

## 為什麼獨立成一支

設計審的散文收斂在本 repo 從沒收斂過(五輪 118 條、每輪都有 blocker;見 [[Projects/規格落成可驗收條件_計劃]])。這道閘把力氣搬到「條款能不能被機器認出來、有沒有接到真的測試、跑起來是紅是綠」。半套所有計劃照舊派審——它不減少審查,只讓「條款有沒有接到測試」變成可見的數字。

## 邊界

只管計劃裡 `[SN]` 那幾行與它們綁的測試。不判門、不放行、不寫審查帳;門與雙向門放行在 [[Projects/雙向門放行_計劃]](待命),逃逸帳在 [[Projects/逃逸自動記_計劃]]。

## 管到的檔

這篇管 `scripts/lumos` 裡的 `cmd_spec_gate`、`_clause_check`、`_clause_grammar`、`_clause_body_of`、`_rollback_section_chars`、`_ran_count`、`_TRIGGER_STOPWORDS`、`_SPEC_GATE_SINCE` 與 doctor 的 S12 段;推送閘 hook 不在這篇(它的家見 [[Systems/bound-tests-gate]] 與 [[Systems/anchor-integrity]])。
