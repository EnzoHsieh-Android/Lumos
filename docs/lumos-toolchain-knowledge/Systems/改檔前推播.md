# 改檔前推播

管的檔:`scripts/hooks/claude/impact-hook.py`。

改檔前把「這次改動牽連到哪些筆記」推到模型眼前的那支 hook。排序與查詢本身在 lumos impact,不在這裡;只執行可信來源的 lumos 見 [[Systems/hook信任邊界]],內層逾時怎麼算見 [[Systems/hook逾時預算]]。

## 用哪個 repo 的圖譜查

預設用 Claude Code 的啟動目錄(沒有就用 hook 收到的目錄)。例外只有一個:被改的檔在同一個 repo 的另一個 worktree 裡,就改用那個 worktree。為什麼只開這個例外、為什麼不跟去不相干的 repo,見摘要的 WHY;當初怎麼發現的見 [[Issues/worktree裡改檔推不出筆記]]。
