## 直接可借的候選(按值得程度排;★全部未立案,待裁★)

### A 組:規則層——三條都是 09-20 修法 A 的輸入,零新機制

修法 A = Enzo 09-01 裁的「第一刀必須是 lumos」真 ablation(帶/不帶各跑同一組任務比前後)。世界給了三個實驗設計上的修正:

- **A1-① 每題重跑 3 次 + 題庫 60/40 分訓練/測試**。出處:Anthropic 官方 skill-creator(anthropics/claude-plugins-official,35.8k★)的 trigger eval——`{"query","should_trigger"}` 20 題、60/40 切、每題跑 3 次、迭代改 description 取測試分最高。對照自家:`scripts/scenario_probe.py` 有 `--sample/--seed/--history`,**我 grep add_argument 沒看到重跑參數**——每題單跑一次。抖動沒估過,帶/不帶的差就分不出是規則效果還是雜訊。最小解=探針加 `--runs N`,結果記通過率而非布林。
- **A1-② 因變數要含「第幾步才敲」,不只「有沒有敲」**。出處:arXiv 2605.10039(2026-05,1,650 場 Claude Code):檔案大小/位置/架構/相鄰檔矛盾四個結構變數「none produced detectable effects after multiple-testing correction」;真正有效的是「each additional function the agent generates is associated with approximately 5.6% lower odds of compliance per step(OR=0.944)」。★這直接打臉「檔太長所以不聽」——聽不聽是**任務內衰退**★。所以 ablation 若只量「首刀是不是 lumos」會漏掉「後半段就不敲了」那一半。
- **A1-③ 先盤成對衝突**。出處:arXiv 2608.02639(2026-07-31):24 條可驗證指令疊 1–20 條,遵循率「falls from ~96% to as low as 20%」,主因是**成對衝突**(一條 output JSON 與另外 9 條不可共存);prompt 編譯對強模型幾乎無效。對照自家:15 萬字規矩從沒盤過哪兩條打架。字串級矛盾偵測有現成起點(ctxlint,10★,規格 CONTEXT_LINT_SPEC.md 41 條),**行為級矛盾全世界沒人做**。
- 同形狀的官方件:`claude plugin eval --ablation with-without`(「Run a no-plugin baseline arm and report the score delta」;grader `tool_used: Skill` 判有沒有觸發;`--runs` 預設 3;`--threshold` 低於即 exit 1;`--max-cost-usd` 超支 exit 2)。★早期存取,本機 CLI 2.1.258 擋「currently in early access」跑不了★;可抄的是 grader 形狀與退出碼語意。
