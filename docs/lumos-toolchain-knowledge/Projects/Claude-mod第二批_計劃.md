# Claude-mod第二批_計劃

白話:Claude Code 的 mod(外掛裡的函式掛鉤)能做到幾件設定檔 hook 做不到的事。這批做一件:壓縮對話前叫摘要保住交棒狀態。第一支 mod(事件帳 [[Systems/lumos事件帳]])只觀察;這件會改摘要指示,所以另開一支 `lumos-context`,不放進只觀察的事件帳外掛。設計審兩輪後縮小範圍(見決策 d1);會談編號那項實作前實測不成立,依計劃停下(見不做)。

PRIOR-ART: 最小解在 Claude Code 的外掛函式掛鉤。官方設定檔 hook 2026-10-06 核對原文:壓縮前那支只能讀到摘要指示、改不了(只能整個擋),壓縮後那支只能旁觀。外掛寫法、市集、測試沿用事件帳(核心邏輯可注入、`claude plugin test`、條款以測試標題開頭綁、Python 端掃外掛原始碼的結構測試)。安裝端的外掛清單不另寫:原樣搬審查席隔離分支已過兩輪代碼審的那一段。

RETIRE-IF: ①上線兩個月內 Enzo 仍得在壓縮後重講交棒狀態——摘要器不照指示做,第 1 項撤掉;②官方 hook 開始支援壓縮前改指示——第 1 項改走官方。

## 範圍

- **做**:
  1. **壓縮前保住交棒狀態**:新外掛 `lumos-context` 掛 `session.compact`,四種觸發(manual、auto、plugin、precompute)都在既有摘要指示後面附一段固定要求:逐字保留使用者在對話裡下的裁定與指示、目前在做的任務與步驟、還在跑或剛交回的背景代理、還沒提交或還沒推的改動、待回覆的問題。用詞不帶 lumos 專用名詞,因為外掛裝在使用者層、所有專案都會生效。附加段第一行是固定標記行 `[lumos-context 交棒要求 v1]`,指示裡已有這一行就不重附。子代理(輸入帶 `agentId`)附精簡版:保留它的任務與已得結論。
- **不做**:
  - 會談編號交給 lumos:2026-10-06 實作前實測(見 [[Verification/2026-10-06_會談編號外掛實測]]),外掛讀到的官方編號是 `claude` 這支程式啟動時繼承來的環境,不是它交給 Bash 的那份——從終端機直接開的會談外掛讀到空值,配對的前提不存在。照做法要點寫好的規則整項停下,不走別的備案;要做得重新設計(例如改用程式編號比對),另開題。
  - 核對審查員引用的檔有沒有真的讀過:設計審兩輪都冒重大發現,根本問題是事件帳沒記搜尋條件與工作目錄,一次沒帶路徑的搜尋就讓整個 repo 都算讀過,檢查幾乎列不出東西。另開題,先讓事件帳多記這兩樣再做。
  - Bash 改檔前推筆記:改觸發條件會弄壞 Codex 那邊的轉換與舊安裝;列舉寫檔形狀違反「列舉補不完」的既有決策;它也不是 mod 能力。
  - 開場標出驗證不過的記憶:拿不到會談編號、要翻記憶清掃的唯讀守衛、標記文字有注入疑慮。另開題。
  - `lumos enforcement` 加外掛有沒有裝的那一列:事件帳筆記有一條近期確認過的 RULE,不准那一列叫外部指令;看不看得到沒裝,另開題。
  - lumos 自己派代理(2026-10-06 本會談列的 mod 候選清單第 7 項,沒進任何計劃節點;Enzo 裁拿掉)。
  - 壓縮後重新注入規矩:lumos 三支開場 hook 沒設觸發條件,照官方文件壓縮後會再跑(未實測)。

## 做法要點

- 第 1 項的附加段固定一份文字放在外掛裡,不呼叫外部指令;原本就有指示(使用者打 `/compact <文字>`)時接在後面,不覆蓋。precompute 算的是當下的對話,真正壓縮時可能已過時——這是引擎行為,附加段只管要求,不保證新鮮。「已有標記行」用整行比對(去頭尾空白後整行相等);原指示不空時先接一個空行再附,空字串、純空白或沒有指示時直接附。子代理精簡版的標記行另一句 `[lumos-context 交棒要求 v1 精簡]`,兩種各判各的。
- 外掛清單:原樣搬審查席隔離分支安裝端那一段(完整 id 清單 `_LUMOS_PLUGINS`、取最差狀態、teardown 確認清單與手動指令跟著清單)與它改好的市集測試,再把 `lumos-context` 加進清單與 `.claude-plugin/marketplace.json`。這段先上主線;隔離分支之後接上時,改用這邊的符號、只加自己那一支。
- 新外掛裝不裝得上:審查席隔離分支 2026-10-06 已在隔離設定資料夾實測,資料夾型市集安裝時直接讀市集檔,不必先更新市集快照。

- [S2] 當摘要指示裡已有交棒要求的固定標記行時,外掛應不再附 [manual:claude plugin test mods/claude/lumos-context 的 S2 測試全綠]
