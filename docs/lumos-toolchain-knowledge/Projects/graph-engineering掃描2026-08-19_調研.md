對照本專案:**新機制準入三問(Growth test)只管該不該建,沒有一問管什麼觀測到了就撤。** 而「散文紀律沒有退場機制」已是立著的 Issue([[Issues/散文紀律沒有退場機制]]):全 repo 零常設退場規定,唯一前例明令禁止刪規則,且被前後量過效果的紀律=0 條。

## 2026-08-22 第三次進場:related 邊型遷移案——★前提不成立,關案★

起點是「Graph Engineering 我們符不符合標準」。外面的說法分兩派:多數指多 agent 編組拓撲(節點=agent/工具/路由/人的關卡),少數指知識怎麼存(節點=實體、邊帶型)。**本專案重心在後者**。

前者的六條清單(角色/邊/失敗模式/交接協定/可觀測性/各管各的)我們五條有,唯一的洞在可觀測性。
★但「缺」的說法查證後是錯的★:`canary record` 的 `--tokens` / `--wallclock-min` 早就在,
只是**零筆填過**。2026-08-22 已把管線接上(自主迴圈解析 `claude -p` 本來就吐的成本 + 派席
範本加參數),見 [[Verification/2026-08-22_成本欄接上與撤除兩階段]]。

### 裁定:不遷移、不加欄位、不做讀側顯示

提過又被打掉的三個方案,理由都留著,免得下次重提:

| 提案 | 為什麼不做 |
|---|---|
| 把驗證篇的 related 歸位到 `verified_by` | **不是機械可判**。那批裡有來源驗證篇自己已 superseded 的(2026-08-03_Windows真機驗證五缺陷修復 → slim 三節點 + 測試假綠形態),歸位會當場觸發 doctor 的失效背書檢查——等於把例行清理才剛拿掉的東西加回去 |
| 刪掉 related 與 `verified_by` 雙記的重複 | **不是零風險**。雙記的那條 related,正是 `verified_by` 日後被降級時唯一存活的歷史連結(guard-kill 2026-08-22 就走了這條路);刪了會製造孤兒 |
| 給事故→機制那組邊一個新具名欄位 | **新機制,過不了准入**:無事故支撐;且成本不是寫欄位那一次,是散落列舉稅(append 白名單、lint 值域、doctor E 家族、impact 邊型、context 顯示、commands 索引六處要同步)——體檢 #7「四份清單漂移」正是這型病 |
| 讀側顯示標「無型」、排在具名欄位後 | 沒有需求方。原本的痛點(「被誰打死的」混在 related 裡)其實由 `lumos decisions` 解掉了——canary-audit 的死亡在決策鏈第五條寫得清清楚楚,讀者不靠邊;且單跳鄰居查詢的抬頭已經在講「弱恆不展」 |

**消融實驗也不跑。** 補鏈建議與 via 枚舉是「廣撒候選、人裁」的建議型功能,沒有 oracle,delta 定義不出來;硬定一個就是為量而量。

### 觀察(不是待辦):related 裡混了七種語意

抽層讀了六十幾條,`related` 底下實際混著:驗證了 / 事故揭露缺陷 / 規則的教訓來源 / 計劃要動這個系統 / 同案的實作篇與設計篇 / 這批接前一批 / 被推翻導致停用。**記下來當觀察,不轉待辦**——上面四個方案已逐條駁回。

### 數字怎麼算(★兩份腳本量同一件事差了 35 條★)

帶 `related` 欄位的節點數 <!--lumos:count=185 re=(?m)^related:$ in=docs/lumos-toolchain-knowledge/**/*.md--> ——這個數字讓 doctor 自己重算。★寫完當天就漂過一次★:本篇的驗證節點一建,177 立刻變 178,Check N 當場喊出來。**這正是可重算標記存在的意義,不是缺陷。**邊數「四百多條」是單次腳本量測,**寫不成可重算標記就不寫精確數**。

兩個 session 各自寫腳本量「驗證篇出發的 related」,一邊 56 一邊 59,互相不可複現。差的 3 條 diff 出來,是 56 那邊的規則漏,真因值得下一個寫掃描腳本的人看:

> ★切 frontmatter 用 `find('\n---')` 當結尾時,最後一個欄位後面沒有換行,任何要求行尾 `\n` 的正則會整塊漏掉;先 `+'\n'` 再比。★

具體症狀:`related:` 剛好是 frontmatter 最後一欄時,那個節點的 related **一條都不算**,而且靜默,不會報錯。漏了 14 個節點、35 條邊,連帶讓所有衍生比例偏低。這與「手寫整檔 frontmatter 忘記結尾 `---`」是同一家族(邊界 off-by-one),差別是那條炸得很明顯,這條無聲。

### 兩個進場失誤,一個有守衛一個沒有

① **0 筆沒換同義詞就跳去 web search**:查「圖譜 工程 標準」0 筆逐詞回退,沒換成原文詞就轉去外面搜,重付了一次已經付過的搜尋成本。今天注入的「查得到才算先行」三條擋得住這個——但範本原話是「不要轉頭去 grep」,**這次是「不要轉頭去 web search」的變體**,同一條規則要讀得出兩種。

② **重推一個 code 早就否決的優化**:related 不入多跳寫在 code 註解裡,圖譜一篇都沒講,所以整輪走完才發現前提不存在。★**這條沒有機械守衛**★——重驗條件:下次有人再提 related 遷移,回頭看這篇有沒有接住他。
