# 圖譜進迴圈入口栓_計劃

PRIOR-ART: **借用既有原語,不建新機制、不加依賴**——A 用既有 `cmd_search` 多詞回退 + `_rank_score_candidates`(BM25F;★前掃訂正:原寫 `_search_index` 不存在;多詞回退=整串 0 命中自動退 OR 召回,正好接住切詞查詢★)(週考全綠:hook P 0.73-0.80、lift 54-82%(all/train/held 三切面全域;「11 門全過」為同日三筆中的完整切面筆),2026-08-24 帳、之後無新帳)+ `loop next` 既有輸出慣例(比照 `record_cmd`/`scope_cap` 的 advisory 段);B 用同一檢索 + `cmd_new` 既有入口。兩條皆 advisory 不擋,對齊「前置加重一律拒」(不加席不加輪,只把既有資訊端到眼前——同 lint 誠實化、pitfalls 提示的既有形態)。**已排除**:機械相似度硬擋(誤殺合法近名如 v2/std 變體;advisory 即可)、把搜尋接進處置閘(閘語意變更須另案)。

## 問題(兩次真實燒錢事故,非假想)

**這條線=「節點搜尋得到 → 迴圈真的用上」。檢索本身健康**(見 PRIOR-ART 考卷數字),漏在兩個入口:

- **開迴圈不看圖譜**:`loop next` 給輪次/席位/記帳模板,不給「這主題圖譜已有什麼」。★事故:impact 鏡頭案(2026-08-29)開案時 `送審前impact鏡頭機械化_計劃`(已裁 A 案、拒加閘)已存在,搜尋一打就中,但無任何機械點代打——兩輪設計審(十席次)燒完才由外家席發現,案停★(詳 [[Projects/impact鏡頭機械化_計劃]]「我方犯的錯」節)。
- **建節點不查近名**:`cmd_new` **完全同名會擋**(既有五道檢查之一;★前掃訂正:原寫零檢查不實★),但**近名零檢查**——掛點現成(同名檢查之後、mkdir 之前)。★同案:建 `impact鏡頭機械化_計劃` 時近名節點連檔名都撞一半,零警告★。這是重造輪子的最後一道本可攔的門。

## 提案(兩條,全 advisory 不擋;r1 三席折入後 v2)

**A. `loop next` 首輪加「主題既有節點」advisory 段**
- 觸發:**只在首輪**(`n_next == 1`,帳齡零必走 plant-canary,與事故時點「開迴圈」一致;比照同函式 `cluster_hint` 的 N=1 抑噪先例 scripts/lumos:5889——逐輪重印=噴無效噪音)。只掛正常 emit 出口;rc2 硬擋出口(如忘帶 --tier)不印。
- 查詢詞(機械規則,無黑名單):
  - 有 `--spec` → **計劃節點檔名優先**當查詢源;編號僅 fallback(實帳 `auto-2026-08-30` 型編號清洗後只剩 `auto`,命中 68 篇零相關——印似是而非的 5 筆比 0 筆更毒)。
  - 查詢源 NFC+lower 後**重用 `_rank_tokenize`**(scripts/lumos:1871,全 repo 唯一 CJK 切詞;禁止另寫第二份)→ 濾純數字 token(「2026」實測命中 381/385=全庫召回)與長度 1 的 ASCII token → 去重。
  - 清洗後 token ≤1 且無 CJK 段 → 印「編號無主題訊號,未查圖譜」(誠實,不假裝查過)。
  - 測試例三枚:`intake-guard`→`intake guard`;`圖譜進迴圈入口栓`→bigram 串(實測 top-5 與人工斷詞完全相同,垃圾 bigram 高 IDF 反而精準);`auto-2026-08-23`→濾後只剩 `auto`→走「無主題訊號」分支。
- 召回:**不走片語→回退管線**,直接 OR 候選+`_rank_score_candidates`(BM25F)排序——★r1 實測:事故本尊查詢 `impact 鏡頭機械化` 片語命中 1 篇即 break(scripts/lumos:2174-2176),0.90 近名整篇被藏;合成查詢不是片語,片語階段結構性漏接★。**superseded/翻案節點必須納入**(「已裁不做」正是最值錢的命中),輸出標 status。
- 印(文字模式):**專屬多行段**,比照 roster 輸出迴圈(scripts/lumos:5905),每筆一行=節點名+status+決策數,title 近名者標 ★近名;**不塞進五鍵白名單**(scripts/lumos:5911)。`--json` 把 `related_nodes` 放進 `out` dict(既有 21 處消費端全逐鍵取值,加鍵不破壞)。
- 誠實零行:掛在「逐詞覆蓋全 0 或 top1 分數低於門檻」,**不掛候選數 0**(CJK bigram 經 OR 幾乎不可能 0 候選,「圖譜」一詞即命中 166 篇)。
- in-process 呼叫檢索必須 redirect stdout/stderr 進 buffer(同函式對 `cmd_loop_status` 已有前例 scripts/lumos:5927),否則 --json 模式 stdout 出現兩行 JSON 弄壞機讀端。
- 一行指路:「先讀再開;近名者尤其要讀它的 decisions」。

**B. `lumos new` 近名「建檔後即告」advisory**
- ★語意更名:原稱「建檔前防撞」在非互動 CLI 自相矛盾(外家 r1:你看到提醒時檔已建)。改為**建檔後即告**——事故裡貴的不是建檔,是之後燒掉的審查輪;告知落在開案那一刻,仍攔在昂貴段之前★。
- 範圍:**限 project/system/issue 三型**(Verification 排除:實測 156 檔 81% 有 ≥0.6 鄰居,日期前綴+「落地/驗證」通用尾詞墊高,天天誤鳴=546 型麻痺)。比對前剝掉開頭 `YYYY-MM-DD_` 前綴。
- 判準:**檔名 difflib ≥0.6 單判準**(原「search 前 2 名帶同詞幹」刪除——repo 無 stemmer,「詞幹」不可實作不可驗收)。
- 命中 → 建檔完成後印「★近名節點已存在:○○(status/決策 N 條)——若同主題,先讀它再繼續;重複開案的成本在後頭★」;低相似/零命中靜默。印 stdout(今天無 headless 呼叫端,test_lumos.py 只斷 rc)。
- Projects 的 top pair 幾乎全是合法 `X_計劃`↔`X_實作計畫` 變體(0.85-0.92,與事故對 0.90 同分段、檔名層不可分離)——advisory 不試圖分離,提醒「先讀計劃」對合法變體反而是 feature。

**兩條共同鐵則:fail-open**——advisory 全體包 try/except,任何內部例外靜默跳過,**絕不改變宿主指令的 rc 與既有輸出**(`loop next` 的 rc 是載重語意 scripts/lumos:5745-5750、21 處測試消費;B 掛在 mkdir 前,炸了會讓「不擋照建」變成建檔失敗)。

## 實務隱患(逐類答;r1 後更新)

- **效能**:search 對 385 篇實測 0.59s(邊界席重測 0.66s);兩入口皆互動指令非熱路徑。已排除。
- **併發/資源/鎖**:純讀索引,`cmd_search` 無任何寫入(含 usage-log)。已排除。
- **回滾**:輸出級改動,`git revert` 即回,無狀態殘留。已排除。
- **不可逆/對外**:不寄送不碰正式環境。已排除。
- **advisory 內部失敗**:見上「fail-open 鐵則」(r1 邊界席補)。
- **★真隱患:A 的查詢詞切不好=垃圾命中★**——處置已進 spec(見提案 A 的機械規則+測試例三枚;r1 正確性席實測背書)。
- **★真隱患:advisory 被無視(546 前例)★**——見「誠實天花板」的根因訂正。不做升級計數器(YAGNI;重驗條件見下)。
- **B 誤報**:已用全量實測收斂(型別縮三、剝日期前綴、單判準;見提案 B)。
- **應試化/零依賴**:不涉/已排除。

## 誠實天花板與重驗條件(r1 訂正)

- **定位=紀律輔助,非根治**。外家 r1 反證成立:同案紀錄明載編排者**跑了提示入口仍忽略**([[Projects/impact鏡頭機械化_計劃]]:53)——根因是紀律沒守,不純是「不知道存在」。A/B 只把資訊送到眼前、降低偶發遺漏,擋不住不讀;機械強制已在 impact 案裁「不做」,本案是那次裁定下最便宜的殘餘手段。
- **自主迴圈消費的坑(r1 邊界席)**:現行 orchestrator-prompt **不跑 `loop next`**,且其 lumos 呼叫全走 `--vault __SCRATCH__/kg`(scratch 近空)——未來若把 related_nodes 接進去而不解 vault 錨定,誠實零行會**恆為假陰性**(系統性說「圖譜沒有」),精準複製本案要防的病。本案不改 orchestrator-prompt;接上前必須先解 vault 指向。
- **重驗**:上線後下一次「重造輪子」事故若再發生,查當時 A/B 有沒有印、印了為何沒用——印了沒用=升級議題(546 計數器再議),沒印=切詞/召回 bug。B 的 0.6 門檻與型別範圍為單次量測,若 Projects 端出現週級誤鳴照樣回這裡調。
