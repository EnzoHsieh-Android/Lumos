# 席位人格化_計劃

> **狀態:待 Enzo 裁,尚未實作。** 三層可分開裁(A 措辭 / B 模型路由 / C 輸出格式),不裁不動。

PRIOR-ART: **借用既有設計為預設**——最小解在派工措辭層,不新建機制、不加依賴、不動任何閘。自家範本已存在:[[Systems/arch-alignment-lens]] §7.6 架構對齊席(立場+明講排除+嚴重度錨),昨天 [[Systems/design-loop]] d6 已把正確性鏡頭升到那個形狀。外部對照:OmO(oh-my-openagent)`.agents/skills/hyperplan/SKILL.md`(2026-08-28 讀)把同一形狀推到「人格+預設姿態+寫死攻擊台詞+模型偏見配角色」。世界背書見下節。

## 一句話

把審查席從「**同一個模型 + 換鏡頭文字**」升成「**每席有立場與預設姿態**」,並(選配)讓不同席位路由到偏見合適的模型。

## 為什麼是現在

- 2026-08-28 d6 把正確性鏡頭從名詞清單升成「問句+例子+明講排除」,那是這條路的第一步,本案是第二步。
- 2026-08-29 問世界查證(見下)顯示:對抗式審查機制的增益**取決於三個生效條件**,我們只差第一條沒做滿。

## 世界怎麼說(2026-08-29 WebSearch 查證)

**生效三條件**(多來源一致):(a) agent 之間**夠不一樣**(不同模型／種子／角色 prompt);(b) 批評**扣在明確步驟或事實上**;(c) 裁判**獎勵可查證推理、懲罰無憑據主張**。
→ 我們 (b)(c) 早就有(逐字引句 ≥10 字 + refcheck 行號機驗 + 拿不出反證不准降級);**(a) 只做到「換鏡頭文字」,模型全同**。本案補的就是 (a)。

**★反面證據(這是本案刻意不碰「互辯」的理由)★**:諂媚式從眾使模型放棄本來正確的推理去附和多數,比例達 **85.5%**;共識塌陷造成 oracle gap **32.3 個百分點**(至少一席已答對、卻在形成共識時被丟掉);辯到第三輪有 **23.9%** 收在「一致的錯誤答案」;另有《共識的代價:孤立自我修正勝過無引導的同質多 agent 辯論》。
→ **本案只取「差異化」,不取「互相攻擊到共識」。** 與既有「禁互辯、席間乾淨脈絡」紀律相容,也與 [[Projects/收斂機制優化調研2026-08-14]] 已裁的「多樣性崩塌不適用我們(席間無密集拓撲)」一致。

## 提案內容(三層,可分開裁)

**A. 席位人格化(措辭層,零額外成本)**
每席派工詞從「鏡頭清單」加上三件:①**立場**(例:簡單的守護者、複雜的敵人)②**預設姿態**(例:預設駁回,只有具體證據才讓步)③**該席專屬的攻擊問句**。範本=既有架構對齊席。

**B. 模型偏見配角色(路由層,成本中性到略增)**
不同席位路由到「天生偏見符合該角色」的模型(偏簡單的模型當反過度設計席、跳脫型模型攻擊正統)。**不加席、不加輪**,只換某席用哪個模型。我們已有跨家族基礎([[Systems/cross-family-audit]] 的外家席),本層是把它從「只用在辯方/否決」擴到「初審席也差異化」。

**C. 輸出格式硬性(措辭層,零額外成本)**
「編號條列、每條 ≤3 句、不准散文段落、不准模稜兩可」。目的是抑噪與可機械收貨。

## 實務隱患(逐類答;無則寫「已排除:理由」)

- **併發／效能／資源**:已排除——本案只改派工措辭與模型選擇,不碰任何執行路徑、鎖、連線。
- **成本**:A/C **零額外 token**(同長度措辭替換);**B 會改變模型分佈,需先量再上**——這是 B 單獨列為待裁的原因。
- **回滾路徑**:A/C 純文字改動,`git revert` 即回;B 另需同步席位分派表(`loop next` 的席位表),回滾時兩處一起。
- **假陽性升高(★真隱患★)**:「預設駁回」的姿態可能推高噪音,與既有**抑噪紀律**(「低嚴重度疑慮,給不出具體失敗場景就不要標」)正面拉扯。處置:A 層落地時**抑噪紀律照舊逐字保留**,且「預設駁回」只約束**姿態**不放寬**證據要求**;上線後看存活率有沒有異常掉。
- **與應試化防護的張力(★真隱患,原提案沒看到★)**:2026-07-28 已裁「rubric 公開固定會被『剛好滿足字面』鑽,派工措辭要**改述、不逐字貼**」。而 C(固定輸出格式)與 A 的「寫死攻擊台詞」正是把措辭釘死——**兩條規矩會打架**。處置建議:攻擊問句寫成**每次改述的範例池**(給 3-5 條、每輪抽/改寫),不是逐字固定台詞;格式硬性只約束**結構**(編號、句數上限),不約束**用詞**。
- **與「前置加重一律拒」教義**:已排除——A/C 不加輪、不加席、不加 token;B 只換模型不加席,亦非加重。若日後任何一層演變成「多派一席」就違教義,當場停。
- **不碰互辯**:已排除——見上節反面證據;席間仍乾淨脈絡、彼此看不到。

## 待裁選項

1. **只裁 A+C(推薦)**:零成本、有世界背書、與既有紀律相容;攻擊問句走「改述範例池」避開應試化衝突。
2. **A+C+B 全上**:多拿「模型差異化」這條最硬的生效條件,但 B 要先量成本與模型可用性。
3. **全部不做**:昨天 d6 的措辭升級效果都還沒量,先讓它跑幾輪再說(見下方誠實天花板——這個理由成立)。

## 誠實天花板與重驗條件

- **昨天 d6 的升級本身還沒量過**(design-loop 護欄段已記:無 A/B,回頭看條件=兩個以上真 loop 跑過後人抽看 findings 有沒有更具體)。本案是**同一條路再往前一步,同樣沒有自家實測**——世界的 +7% 是在別人的基準上量的,不保證落到我們(我們起點已有引句錨定+行號機驗+外家反證三層)。
- **重驗條件**:A/C 若落地,兩個以上真 loop 後比對「存活 findings 的具體度」與「噪音條數」;噪音明顯上升即回退「預設駁回」措辭。B 若落地,先量單輪成本變化,超過 +15% 就停。
- 這層天花板與 [[Systems/design-loop]] 既有定位一致:設計審是**便宜初篩網**,正確性歸下游代碼審與測試。
