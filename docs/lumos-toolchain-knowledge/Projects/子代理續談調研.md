# 子代理續談調研

## 這是什麼

Claude Code 新增「子代理續談」：派出去的子代理完成後，其對話脈絡（讀過的檔案、推理過程）保留在本機紀錄檔，同一 session 內可用 SendMessage（帶 agent ID / 名字）繼續追問，它帶著原記憶回答。限同 session、macOS/Linux。另有 agent teams（另一個實驗中的多 agent 組隊功能：成員之間可直接互傳訊息、共享任務清單，與「子代理只回報主 agent」是兩種模式）仍在實驗旗標後面，未納入本調研裁定。

## 對我們的價值（三場景，均為「報告之後」的環節）

我們的 loop 機制（design-loop / code-loop / subagent-driven 複審）刻意讓審查員**無脈絡進場**——這與續談不衝突：續談補的是「交報告之後的來回」。

1. **追問取代重派**：審計報告錨定引句缺漏、某條 finding 模糊 → 直接傳「把你第 N 條的原文依據貼出來」，免整輪重跑。
2. **攻防加一回合**：code-loop 辯方殺假陽性後，把反駁傳回原審查員答辯一輪再裁，不必重餵 diff。
3. **原審查員驗修**：修完 finding 後由「發現它的那席」帶記憶驗收「這修法有沒有解我報的那條」；收尾仍派全新席掃回歸。

## ★禁令★（若日後採用，此條必須同步寫進 skill）

**各輪審計的「初讀」永遠派全新無脈絡 agent，不得以續談替代。** 兩個理由：

- canary 機制被打穿：跨輪續談的審計員看過上輪植入樣式，注意力探針失效（[[Systems/canary-audit]]）。
- 脈絡只增不減：續談 agent 逐輪逼近 ≈30K token 審讀天花板（[[Projects/審查規模對照實驗]]：超過即 findings 歸零）。

界線一句話：**「讀材料下判斷」派新的；「對它自己講過的話追問」才續談。**

## 2026-08-14 實測（本機證據鏈）

環境：宿主進程 v2.1.229，Ghostty 終端手動啟動的**互動式** session（`claude --chrome --dangerously-skip-permissions`；父進程鏈=login→zsh→claude，無 tmux）；磁碟已裝最新 2.1.232（宿主進程長駐未重啟故仍載舊版）。環境變數帶 `CLAUDE_CODE_CHILD_SESSION=1` 與 claude.ai 橋接編號——後者是新版把每個 session 註冊到 claude.ai 供網頁/遠端接手的機制，**與本故障無關**（初判「桌面 App 橋接所致」已被下面第 6 步推翻）。

1. 派 foreground 子代理（claude-code-guide 調研任務）→ 完成，spawn 結果明示可 SendMessage 續談。
2. SendMessage 過去 → `could not be resumed: No transcript found for agent ID`。
3. 磁碟驗屍：`~/.claude/projects/<本專案>/<session>/subagents/` 只有 `agent-*.meta.json`；tasks 目錄的 `.output` symlink 指向應有的 `agent-*.jsonl`——**目標檔從未被寫出（斷頭 symlink）**。本專案七月至今所有 session 皆此型（144 個 meta、0 正文，含 KDS 專案同型）。
4. 本專案連**主對話** jsonl 也為零；對照組：`-governance` 專案（cron headless session）主對話與子代理正文 jsonl 均完整存在，其他 headless 專案亦同。
5. 排除 tmux（#70219 那型）：TERM=ghostty、無 TMUX 變數；排除 `cleanupPeriodDays`（settings.json 未設）。
6. **決定性對照實驗**：在同專案目錄跑 headless `claude -p "reply ok"`（吃磁碟最新 2.1.232）→ 跑完 session jsonl **立即落地**。故排除專案目錄/機器設定因素。
7. 結論：**故障面 = 互動式 session 不寫 transcript（headless 正常）**，與已知 issue #66486「v2.1.169+ interactive sessions write no JSONL」描述吻合；非版本落差（七月更舊版同症）、非專案設定、非雲端/桌面橋接。

## 裁定與重啟條件（2026-08-14 同日：重啟條件已達成）

- 原裁定：**暫不把續談納入任何 loop 機制的依賴**；重啟條件=任一本機環境實測續談成功一次（含追問到前輪具體內容、確認記憶還在）。
- **同日達成**：headless 三步實測全過（transcript 落地／SendMessage 恢復子代理／跨兩次 resume 記憶完整，含逐字複述首輪回覆），見 [[Verification/2026-08-14_子代理續談headless實測]]。
- 現況結論：**headless 環境（governance 排程、自主迭代 loop）技術上可用；互動式 session 仍不可用**（transcript 不落地）。
- **已執行（同日 Enzo 拍板）**：寫入完成——`lumos-design-loop/SKILL.md` 新增〈子代理續談〉節作**單源**（環境門檻／追問補件／辯方答辯回合／初讀禁令／拒答≠失憶）；`lumos-code-loop/SKILL.md` 「一眼看懂」加增量條（原 reviewer 驗修，明文不替代翻紅釘證據制與收斂前全新 delta 回歸席）。場景③驗修歸 code-loop、①②歸 design-loop。
