## 順序與限制

- S1 只讀凍結材料、不動任何檔,現在就跑。
- S2–S4 要改的檔(兩支入口頁、派工範本、scripts/lumos)正在被 `code-資安席與多平台指令` 第三輪外家席審;而 skill 以符號連結掛在本機,一改所有工作階段立刻生效——等那條代碼審收完再動,改的時候整檔原子換掉。
