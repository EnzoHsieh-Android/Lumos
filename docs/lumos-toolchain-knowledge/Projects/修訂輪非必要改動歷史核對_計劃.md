# 修訂輪非必要改動歷史核對_計劃

白話：先看返工是不是由風格建議造成，再決定是否要降噪；不能用少報真問題換取輪數下降。

WHY:先核對固定歷史樣本再採用降噪規則 [出處:使用者2026-10-07繼續授權與Claude公開片段對照] [因:minor與非必要建議不是同一件事]
PRIOR-ART:Anthropic服務文件提出修訂輪抑制新增nits；本專案已有純風格不列、辯方查證、修補與重構分段，故先借用既有報告與收貨證據，避免另造分類器。
RETIRE-IF:來源ID或處置核對失敗、歷史證據不能支持分類，撤回對應結論；任一候選延後已證實行為問題、合約義務或必跑閘，撤回候選。只有單功能样本時不外推全專案成效。
REVISIT:2026-10-21 依既有實輪觀察入口核對後續樣本的非必要修補與真退化；本次歷史核對不量測模型漏報率、修補耗時或輪數改善。

## 最小實驗與驗收

固定本分支b31337db的code-convergence-input-guards前兩輪收貨及原席報告。完整枚舉R1六ID、R2三席ID加一編排者機械補充，合計10ID，不把重複根因當獨立產品缺陷。逐項核對保留、反證或自選建議；另保留修復中已被原架構測試抓住的退化事件，不編造第11個席finding。

驗收：①ID完整且來源固定與指紋可重算；②既有九個folded ID全部保留，既有refuted一項維持原證據處置；③只延後有明確自選理由且無行為、合約、測試有效性或必跑閘義務的建議；④負控制可指出以minor或機檢來源直接排除時遺失的真義務。這是人工分類與確定性集合核對，並非模型A/B或新增產品測試。

## 決策與回退

可選直接禁止minor、直接禁止機檢發現、或逐項依既有證據核對；選第三種。代價是人工核對成本；若本樣本沒有可延後項目，不實作降噪規則，優先沿既有測試有效性與保留案例觀察。回退只撤回研究候選，既有原報、severity、處置、閘及輪數保持其歷史意義。

## 歷史核對結果與採用界線

固定樣本10ID中九項folded、一項由既有辯方證據refuted，純風格／自選重構0項。九項原必要處置全部保留，延後0項；完整逐項原始收貨行及來源指紋存於governance/research/review-repair-regressions/claude-review-comparison/historical-dispositions/census.json與report.md。九個席ID加一機檢ID不等於10個獨立產品缺陷，重複根因與測試可信度問題分開說明。

負控制：一律忽略原minor會漏掉key-F1測試偵測力義務；一律忽略機檢來源會漏掉lint-F1真新增複雜度義務。alignment-F1原major、辯方minor仍是診斷錯誤。分類由人工按歷史證據核對，集合檢查只證ID與保留清單一致，沒有測量模型遵循或新跑產品。

這份樣本不支持優先加降噪規則；採用決定是保留既有流程，優先沿[[Projects/高風險修補測試有效性抽查_計劃]]及[[Projects/根因修復與行為保留配對_計劃]]的既定實輪入口觀察。既有辯方反證避免無效修補、原架構釘攔住修補新生退化的歷史證據支持這個優先順序，但不外推實輪輪數已下降。done只表示完成本次固定歷史核對，不代表候選實輪觀察已收尾。
