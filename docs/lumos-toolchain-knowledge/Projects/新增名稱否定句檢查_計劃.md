# 新增名稱否定句檢查_計劃

白話:舊句檢查(m1)抓的是「程式裡某個名稱拆掉了,筆記還在講它」;這一篇要的是反方向——「程式新增了某個東西,筆記還寫著『沒有/還沒有它』」。照舊句檢查的骨架先量再定判法。**量的結論是不做成檢查**:rtb 那兩處真漂移(A3、A7)的句子根本沒寫新東西的名字(寫的是「執行行程那一側的操作狀態尚未定義」「執行閘沒有單筆變動比例上限」),拿新名稱去比對結構上對不到;三組資料列出的 122 行也沒有一行是真的。比較便宜的路是寫法:會過期的「還沒有 X」旁邊配一行機器判得了的回頭條件,交給既有的探針。這個結論跟 Enzo 2026-09-30「做這種檢查」的裁定方向相反,要 Enzo 確認(〈下一步〉)。
