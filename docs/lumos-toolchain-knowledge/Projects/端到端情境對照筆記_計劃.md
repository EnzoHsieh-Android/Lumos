# 端到端情境對照筆記_計劃

白話:Android 端到端驗收的使用情境記在兩個地方:功能對照表(`.lumos/macrobench.json` 的 `e2e.features`)管「跑什麼」,圖譜筆記管「這個情境為什麼要成立」。兩邊靠同一支流程檔對上,但沒有機器檢查,改了一邊另一邊會悄悄分岔。這份計劃在既有的涵蓋報告 `lumos android-e2e coverage` 多列兩項:對照表裡哪些情境沒有任何筆記提到、筆記綁了哪些流程對照表沒列。只報告、不擋。2026-10-27 Enzo 回「我覺得可以補」開工。

PRIOR-ART: 最小解在既有涵蓋報告多兩項,不另開子指令;世界解過:需求追溯矩陣(requirements traceability matrix)雙向列「需求沒有測試」與「測試對不到需求」,Cucumber 的 `--dry-run` 列沒有步驟定義的情境;借用「雙向各列一份缺口」的報法。筆記裡的流程綁定照合約測試綁定那一套解(`extract_contracts` 抽合約行、`resolve_test_refs` 解平台前綴、平台設定 `load_platforms`),流程檔的名字從 maestro 平台的測試名索引反查(殘留索引原本那段抽成共用的 `_platform_name_files`,走 `_walk_test_files`,不另讀流程檔);讀整個圖譜用有上限、不跟捷徑的 `load_vault_safe`(doctor 那一行有 10 秒上限)。自建只有比對本身。
RETIRE-IF: 上線三個月後,KDS 與 macrobench-lab 兩個專案的這兩項一直是 0、或使用者說沒在看,就把這兩項與 doctor 那一段撤掉。

## 報告多列什麼

4. 沒有筆記的情境:列了流程檔(`flows`)的情境,底下每一支流程檔都沒被任何筆記提到,就列成「功能.情境」。「提到」兩種都算:
   - 某篇筆記摘要的 `★INVARIANT★` 合約行用 `[test:<平台>:<名>]` 綁了它,平台在 `.lumos/config.json` 的 `platforms` 用的是 maestro 設定檔,`<名>` 是那支流程檔 `name:` 的值;
   - 某篇筆記全文出現那支流程檔的路徑(照對照表的寫法,去掉開頭 `./`;正文前面多寫 `./` 也算)。路徑前後要是邊界:緊貼英數、底線、連字號、點或斜線的不算(`old/.maestro/login.yaml`、`.maestro/login.yaml.bak` 是別的檔),中文或標點緊貼照算。README 教「不確定是不是合約就不要標,改在正文寫一句指向那支流程檔」,所以只寫在正文也要算。
   只列效能、記憶體、截圖而沒有流程檔的情境不看(它們沒有流程檔可對)。
5. 筆記綁了、對照表沒列:合約行綁到 maestro 平台的名字,對不到任何情境列的流程檔的 `name:`,就列「筆記、名字」。對照表 `e2e.flows` 有列、但沒有情境用到的流程檔也算在這一項(按功能跑永遠跑不到那條合約)。

- 專案沒有知識圖譜:這兩項不看,文字版印一行「沒有知識圖譜,情境與筆記的對照不看」,`--json` 兩項是 `null`。
- 平台設定讀不懂(`load_platforms` 丟出錯誤):綁定那一種不看、只看正文提到路徑,文字版印一行原因。
- `--json` 多兩個鍵:`cases_without_notes`(「功能.情境」清單)、`note_flows_not_in_cases`(`{"note", "name"}` 清單)。
- `--changed` 不影響這兩項(照第 2、3 項:整份對照表都看)。
- 回傳碼照舊:報告印得出來就回 0。

## 還有哪裡看得到

- `lumos doctor` AE 段那一行多一個數字「N 個情境沒有筆記提到」;沒有知識圖譜就不加這一段,四個數字都是 0 照舊不印整行。
- README 中英兩版〈在筆記裡分出使用情境、綁上測試〉那段「目前兩邊沒有機器連起來」改寫成涵蓋報告會列兩邊對不上的地方。

## 不做

- 不擋推送、不擋提交:合約照「不確定就不標」的鐵則,不能逼每個情境都有一行合約;正文提到也算,而那種寫法閘無從判斷寫得對不對。
- 不檢查流程經過哪幾篇節點、順序對不對:連結本身沒有順序,要表達順序另開 MOC 給人讀。
- 不看 `[test:]` 以外的寫法(例如 `[manual:]` 或驗證紀錄):那些不是對照表的情境。

## 實務隱患

- 已排除:金流:只讀設定、流程檔與圖譜,不碰交易。
- 已排除:對外送出:只印到終端。
- 已排除:不可逆:不寫任何檔、不寫治理帳。
- 已排除:守衛面:不擋推送也不擋提交;推送前判定的程式不動。
- 圖譜大(上千篇):每篇讀一次、抽一次合約行;doctor 那一行既有的 10 秒上限只管列檔那一步,讀圖譜靠 `load_vault_safe` 自己的檔數與大小上限(本 repo 948 篇讀一次約 0.05 秒)。
- 流程檔讀不到或沒有 `name:`:那支只能靠「正文提到路徑」對上,不當成讀檔錯誤擋下。
