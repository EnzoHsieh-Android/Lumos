# c6不看連結標題裡的待定詞_計劃

白話:c6 是存量漂移檢查的一種——一句話連到一篇已經收尾的筆記,同一句卻還寫「待裁定、還沒做」這類詞,就提醒「這句可能過期了」。問題是它找待定詞時,連結本身的文字也算進去:rtb 有一篇 Issue 叫〈確認頁顯示AI說明時的收據還沒做〉,已經結案;別篇寫「(已結案,見 〈確認頁顯示AI說明時的收據還沒做〉那篇的連結)」,c6 就因為連結裡的「還沒做」把它列出來。這次改成:找待定詞前先把連結整段遮掉,連結外面真的寫了待定詞才算。

依據:Enzo 交棒單的 rtb 待辦;rtb 2026-10-06 盤點文件 1-1 與工具鏈回覆的排序(本項排第 2)。

PRIOR-ART: 同一支判定已經用同樣的「等長佔位字遮掉」處理已裁定括號(`_drift_mask_settled`)與全形引號(`_drift_mask_quotes`);本案照同一個做法,只在判待定詞的那一步多遮連結,不動找連結的那一步。
RETIRE-IF: c6 改成不再用字面詞表判待定(例如改讀結構化欄位)時,這一步遮連結跟著撤掉。

## 範圍

- 做:`_drift_pending_clause` 判有沒有待定詞前,先把子句裡的 `[[…]]` 換成等長佔位字;「已補已裁定括號就不算」的判斷不變。
- 不做:連結的別名(`[[X|顯示字]]`)另外處理——顯示字一樣是連結的一部分,一起遮。
- 不做:摘要的 DECISION 行判待定(另一支,不經過這裡)。

## 實務隱患

- **連結外沒寫待定詞、只靠連結標題表達待定**:例如只寫「見」加一個連到標題含「還沒做」的已結案筆記的連結——改後不列。這種句子本來就沒說自己待定,不列是對的。
- 已排除:金流:只改筆記檢查的比對,不碰任何金流
- 已排除:對外送出:不連網、不送任何東西出去
- 已排除:不可逆:只改判定,退回提交即恢復
- 已排除:守衛面:c6 推送時只列出不擋;改的是減少誤報,不放寬任何會擋的判定

## 驗收條款

- [S1] 當一行連到一篇標題含待定詞的已收尾筆記、連結外面沒有待定詞時,c6 應 不列出;連結外面寫了待定詞時 應 照列 [test:t_drift_c6_ignores_link_title_words]

## 回退

退回本案的提交即可:只改 c6 判待定詞的一步。
