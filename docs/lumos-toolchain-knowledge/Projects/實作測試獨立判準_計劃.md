# 實作測試獨立判準_計劃

## 目的與範圍

防止日後實作功能時產生和正式算法同源的測試，或只有原始碼字串斷言而未驗行為。使用者於 2026-10-07 同意六條規範，另要求 README 明顯強調測試必須實際有用。這次連接共用規範、開發與審查入口，不修改盤點中的兩支測試。

PRIOR-ART: 採用 Matt Pocock 的獨立預期值與行為測試原則 https://github.com/mattpocock/skills/blob/main/skills/engineering/tdd/tests.md ；延用既有修補故障驗證，不增加全域 mutation runner。
RETIRE-IF: 當測試品質規範被另一份同等涵蓋獨立判準、情境成立與抓錯證據的共用標準取代時，刪除本節並將所有入口改指新來源。

## 驗收

- README 有易懂的壞例／好例，清楚區分人工要求與機械格式檢查。
- Claude／Codex 入口由紀律範本產生；實作與審查派工都指向同一完整規範。
- 既有文件指路、入口一致性與圖譜檢查通過。
