# 測試三項證據實驗_計劃

## 目的與凍結設計

使用者要求實驗結論轉為各棧接入測試撰寫與工具檢驗標準。這次只驗證判準互補性，不量測模型讀手冊的因果效果或代碼審輪數。
PRIOR-ART: 借用 Google Change-Detector Tests https://testing.googleblog.com/2015/01/testing-on-toilet-change-detector-tests.html 與 Oracle Problem Survey https://discovery.ucl.ac.uk/id/eprint/1471263/ 的行為／判準區分；以固定可信案例實跑，不自建通用 mutation engine。
RETIRE-IF: 各棧既有考卷可重現全部反例並保留等量歸因證據時，撤除本固定示範 runner，保留共用標準。

## 條款

- [S1] 當執行固定案例时，實驗應保存 Python 與選配 Node 的來源、hash、版本與每條斷言結果。 [manual:執行固定 runner 核對報告與原始證據]
- [S2] 當只查故障翻紅與重構仍綠时，實驗應展示重抄測試仍能滿足這兩項，避免宣稱它們證明判準獨立。 [manual:核對 copied-correct 與 copied-wrong 的結果]
- [S3] 當判準來源經人工審查时，標準應另外要求独立需求例子與失敗歸因，不讓自述或 JSON 欄位充當語意證明。 [manual:逐項核對共用手冊與接入標準]
- [S4] 當各棧接入时，標準應要求本機 runner 資格考卷並分列 planned、synthetic-verified、project-verified，缺工具或零測試不得通過。 [manual:核對各棧接入表與本次實跑範圍]

固定需求：整數金額，100 元折扣 10% 得 90；另有 200 元得 180、0 元得 0。五種測試：獨立已知答案、重抄正確算法、重抄錯誤折扣、來源結構、僅穩定性。五個版本：正確原版、錯誤折扣12%、固定回傳0、保持行為的改名重構、還原原版。各測試在各版本凍結執行，錯誤折扣測試的 baseline 指錯誤折扣版，不混成正式正确基準。結果预期事前固定在 runner；所有互相組合均保存。

## 回退

唯讀既有來源、只執行 repo 內固定可信字串與暫存檔案；不接受模型輸出或任意測試命令、不連外部服務、不改 CI 閘。回退刪除本實驗與標準入口，不影響原掃描器。
