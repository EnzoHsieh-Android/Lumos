## 目的與範圍

使用者確認以 main 為底，採用本次對話提出的文案方向：以舊客戶端相容安排說明脈絡的用途，提前展示提交阻擋實例，降低術語密度，讓圖與正文同樣保留能力邊界。中英文同步，保留工具輸出原文與既有功能設定。

PRIOR-ART: 沿用專案既有 README 章節、details 展開區與 SVG 產生器；本次是已核可的編輯修訂，不新增機制或依賴。
RETIRE-IF: 若讀者測試顯示相容欄位例子仍無法區分實作與外部限制，改用讀者熟悉的接手案例；若摘要圖不足以辨識檢查時機，再補圖例而非堆入全部規則。

## 編輯與驗證

此為低風險文案與圖示排版調整，略過獨立設計迴圈；不變更 Lumos 執行與放行規則。
