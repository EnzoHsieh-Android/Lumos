# Human fixture specification

R1: integer amount 100 must produce charge 90; 200 must produce 180; 0 must produce 0.
The equivalence experiment domain is nonnegative integer amounts divisible by 100.
R2: POST /quotes with amount 100 returns status 201 and exactly {"charged":90}; one quote row persists with amount100/charge90.
R3: negative amount returns 422 with amount validation error and persists no quote.
All framework tests use testing + SQLite :memory:, array mail/session/cache. No external services.
Counterexamples are deliberately weak tests; their green result never qualifies them as useful.
