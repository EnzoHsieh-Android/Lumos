    *   **問題**: 邏輯錯誤導致 Git 指令必將失敗。`tempfile.mkdtemp` 會先建立一個目錄，而 `git worktree add` 的標準行為是要求目標路徑不得存在（除非該目錄為空且版本較新，但在多數環境中會因路徑已存在而噴出 `fatal: '...' already exists`）。
