## 先查世界

PRIOR-ART:HTML 註解——CommonMark 0.31.2:HTML 區塊第 2 型起始條件是「行首是 `<!--`」、結束條件是「該行含 `-->`」,沒遇到結束就到文件(或容器)結尾;行內 raw HTML 的註解定義是「`<!-->`、`<!--->`,或 `<!--` 接不含 `-->` 的字串再接 `-->`」,沒閉合就不是註解、照一般文字(https://spec.commonmark.org/0.31.2/ 4.6 HTML blocks、6.6 Raw HTML)。採用:行首(前面至多 3 個空白)的 `<!--` 照區塊規則到含 `-->` 的那一行或文件結尾;行中的 `<!--` 只有後面真的有 `-->` 才算註解,`<!-->`、`<!--->` 算完整註解;圍欄與行內程式碼內一律不算。
PRIOR-ART:判路徑換形狀(同一個判讀第二輪被打穿)——git 官方 `git ls-tree -r -z --full-tree <tree>` 一次列出整棵樹的路徑、模式與物件類型(https://git-scm.com/docs/git-ls-tree );採用:每個 HEAD 只列一次、程序內快取成 {路徑: (模式, 類型)},判存在、判檔案、跟著符號連結走(在清單內解析、最多 8 跳、最後要落在 blob)都在清單裡查,`:行號` 才另讀那支 blob 的行數(同一支只讀一次)。排除:每個路徑各開 git(資源席量到每份計劃 0.8 秒)。
PRIOR-ART:舊筆記與程式對不上——專案紀律第 3 條:筆記與程式不符以程式碼為準,改正筆記。
