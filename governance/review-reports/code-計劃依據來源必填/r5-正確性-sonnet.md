**前輪驗收與新程式的實跑**

我在 `git clone --shared` 出來的臨時 repo 和一個自造的臨時 repo 裡跑,並跑了 `python3.14 scripts/test_lumos.py -k psrc`,250 條全過。

|---|---|---|---|
