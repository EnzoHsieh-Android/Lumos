## 為什麼不全照它的建議改(這是判斷,不是偷懶)

它的多數建議方向是「把口語改成書面語」。但這份 README 的語氣是刻意的口語,
★把它改成書面語不是改善,是把資產改掉★。三個具體例子:

| 它想改的 | 它的建議 | 我的處置 |
|---|---|---|
| 「手在鍵盤上，就不可能同時推進三個東西」 | 「親手操作時，注意力和雙手無法同時推進多項工作」 | ✗ 不採納改法。原句更準也更有力;我只拿掉「序列注意力的定義」這個學術詞 |
| 「你練的那件事在貶值，你留下的脈絡不會」 | 「你累積的純實作能力會逐漸貶值，留下脈絡的價值不會」 | ✗ 不採納。這是全篇最有力的一句,改完就沒了;只修「投入報酬」那個怪搭配 |
| 「它們不綁任何一個專案，所以住在這裡」 | 「因此放在這裡」 | ✗ 擬人化是刻意的。只拆句,不改詞 |

**它抓得最準的三條**(這些是真的錯,不是風格問題):

1. **「重話」會被誤讀**——中文裡那通常指「語氣嚴厲的話」,拿來指「載重的宣稱」會讓人卡一下。改成「『這裡不能改』這種話」。
2. **「裝完之後，你不用背任何指令」跟前文重複承諾**——同一件事講兩次,跟使用者稍早自己抓到的重複是同一型。
3. **「依由淺到深」語法不完整**、**「日常你不用敲，但想查得到」句尾沒收完**——純粹的語法錯,沒有爭議。
