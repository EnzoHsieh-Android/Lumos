## Finding 1:切句切點不全,沒有標點的「不做 A + 要做 B」整行被當成不做

severity: major
blocking: 是 — 真的要做的危險事被判成「不做」跳過,風險判低,正是最怕的失敗方向
引句:「_NOGO_CLAUSE_SPLIT_RE = re.compile(r"[,，;；。:：()（）【】\[\]]|但是|但|而是|只有|只|另外|同時|並且|改成|改為|還要|也要"」

問題:切點只有上面那幾個。每一句都只看開頭,沒有切到的轉折會讓後半句被併進前面的否定句,後半句的危險詞就跟著被跳過。實測沒被切開的有:
- 全形與半形的 `！ ？ ! ? . …`
- 破折號 `--`、`—`、`·`、`・`、`->`、`=>`、`+`、`&`、`|`
- 中文連接詞與轉折詞:`改用`、`改以`、`先做`、`僅做`、`並`、`且`、`還有`、`與`、`及`、`、`
- 英文轉折詞:`then`、`so`、`yet`、`however`、`while`、`with`、`plus`、`whereas`
- 英文大小寫混用的 `not`

`_NOGO_NEG_PREFIX_RE` 只看句首,前綴又涵蓋 `不做`、`排除`、`本期不`、`won't` 這類短詞,所以整行只要開頭是否定就過。

具體失敗情境(我用 `_nogo_skip_lines` 實跑,「## 不做」節下的清單):

| 輸入行 | 結果 |
|---|---|
| `- 不做退款！做扣款` | 判成不做,跳過 |
| `- 不做退款改用 stripe 扣款` | 判成不做,跳過 |
| `- 不做 A. send webhook to partner` | 判成不做,跳過 |
| `- 不做退款 -- DROP TABLE users` | 判成不做,跳過 |
| `- 不做 refund then send webhook` | 判成不做,跳過 |

輸出的跳過行號涵蓋了這五行。對照組有切開的寫法(`，但要 DROP TABLE`、子項目 `  - 實作扣款`)都正確保留為照掃。

結果:這份計劃的金流、對外送出、不可逆關鍵字全被當成不做,`_door_judge` 的 `signals` 為空,四類各補一行合格已排除就判成風險低,放行走小改動閘。`nogo_skipped` 只會留一筆指紋,沒有人會看。

建議:
- 把切點反過來,改成「整句只能由否定片語加上名詞片語組成」:例如不含任何動詞或轉折詞才算。
- 或者縮小跳過範圍:只放行「否定片語後面全是被否定對象」的句子,其餘有疑慮的整行照掃。

佐證:``scripts/lumos:7933``(`_NOGO_CLAUSE_SPLIT_RE`)、``scripts/lumos:7999``(`_nogo_line_says_nogo`)、``scripts/lumos:8031``(`_nogo_skip_lines` 內逐行判)。
