# code-規格閘不做節 r2 收貨紀錄

七席全回(正確性、併發、邊界、合約、通才、架構對齊、資安),全部 report-normalize 不用改、quote-check 全數錨定。共 15 條:正1–3、併1、邊1–2、合1–2、通1、架1–3、資1–3。

## 處置

同輪有 blocker(資1)與多條 major,accepted 必空,15 條全部折入(修正紀錄 r2-fix.json 分 G1–G8)。

- G1 否定字樣整行子字串太寬(資1、合1、正1、邊1、通1、併1)+ 資3:改逐句判,每句以否定片語開頭。資3 建議的「略過非空就不准判低」不採(不做節就不能寫任何危險詞,功能失效);它另兩個建議(緊貼否定、子項目各自判)由 G1/G2 做到,略過的詞在 spec-gate 輸出照印。
- G2 子項目與續行繼承(資2):各自判。
- G3 全形空白子項目(正2)。G4 釘值範圍(正3)。G5 縮排改用既有函式(架1)。G6 註解(架2)。G7 測試缺口(邊2)。
- G8 兩層版本號靠人記得升(架3、合2):註解與家筆記寫明連動順序與守它的兩支測試。
