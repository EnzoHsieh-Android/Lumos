blocking: 是 — 否定字樣的比對只看項目行裡有沒有「不」「無」這個字,沒看語意。連關鍵字表的 `不可逆` 本身都會被當成否定。r1 加這條規則,就是要擋「偽裝成不做的實作」,現在這條規則可以被一個詞繞過。
引句:「不|沒有|無|排除|暫緩|非本期|\bout of scope\b|\bnot\b」
問題:中文那幾個字用的是子字串比對。`不可逆` 是 `prod-irreversible` 類的關鍵字,所以命中這個關鍵字的行,自己就會通過否定檢查,關鍵字等於替自己作保。
具體失敗情境:
- 計劃寫「`## 不做`」,下面放「- 本版會做不可逆的資料遷移」。實測這行被跳過,不計入風險。
- 同一節的「- 本版會做 DROP TABLE users」不含否定字,照掃,所以行為前後不一致。
- 同一個根因還有:「不只」「不僅」(意思是做得更多)、「不斷」「不錯」、「無論」「無限制」這類詞,以及「(不含重試)扣款」。含這些詞的項目,即使整句在說要做,也被當成否定而跳過。
- 實測「不只退款也要做刪除帳號」「這個資料庫刪除功能不錯要做」「無論如何都要刪除帳號」三行都被跳過。
- 英文那邊相反,方向是保守的:`cannot`、`nothing`、全形 `ｎｏｔ` 沒被認成否定,所以照掃。這只會多報風險,不會漏報。
