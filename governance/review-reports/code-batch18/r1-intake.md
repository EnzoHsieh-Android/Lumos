## ★通才席用「真的跑 pre-push」抓到兩條,兩條都打在我的宣稱上★

**① 我那條測試從頭到尾沒跑過 pre-push。** 它的名字與說明都寫著在驗推送關卡的
「算一次、兩個消費者各讀一次」,但每一條斷言都是直接呼叫 CLI。
席位做了個 mutant 把 hook 裡那支改成永遠重算——**34/34 全過、沒有任何一條翻紅**。
★這批存在的理由就是那個成本,而它沒有守衛。★

補了 `t_prepush_computes_impact_once`:用一個會記自己 argv 的假 lumos 頂替真的,
跑一次真的 pre-push,數「算波及只准出現一次」「兩個消費者都要帶 --from-json」
「低風險那條要帶 --advisory」。拿席位那個 mutant 重跑:**翻紅**;
另外兩個 mutant(同步點名退回自己算、低風險整個不跑)各翻 3 條與 2 條。

**② 我寫的「一次推送只算一次波及」只在低風險成立。**
高風險那條走 `code-loop check`,而它裡面那一步沒吃那份算好的、自己又算了一次。
★處置不是把話改小,是把它接上★:`code-loop check` 加 `--from-json`,pre-push 傳進去。
