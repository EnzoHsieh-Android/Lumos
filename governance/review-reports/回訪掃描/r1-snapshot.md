# 回訪掃描_計劃

PRIOR-ART: **借用既有形態,一個掃描器治 52 件**——doctor 軟提醒段(E4 連鎖票同形:全靜默設計/warn_soft cap3/gov event/advice 獨立行)+ 行格式慣例(REVISIT 行,同 ★INVARIANT★/PRIOR-ART 行內標記家族)。**已排除**:52 個客製鬧鐘(維護災難)、新指令當打卡鍵(編輯該行本身=打卡,鬧鐘指到哪改到哪)、通用 cron 框架(doctor 已每日跑,不加第二個心跳)、自動計數「N 次後」型(各自要專屬計數器=過度工程;一律轉日期落地)。

## 問題(2026-08-31 全圖盤點,乾淨 agent 實掃)

**52 件「靠人記得才會發生」的約定**,三個結構洞:
1. `revalidate_when` 與正文裡所有「YYYY-MM-DD 覆核」「N 次後回看」條款**沒有任何掃描器**——帶日期的覆核集中在 2026-09-26/2026-11-26/2027-02 三個沒人守的日子。
2. **「下一個真實迴圈驗收」家族是最大宗隱形壞帳**:事件天天發生、承諾從不被喚起;至少三件條件已成立未執行(其一計劃已標 done 而 S6 查無驗證回寫)。
3. 待裁事項散在十餘張 open Issue,無任何機制定期端到人面前(nags 週報只升級「閘在唸的節點」)。
盤點全文(A 已機械 7 類/B 事件驅動 11 類/C 純靠人記 52 項逐條)=本輪審查留痕 `governance/review-reports/回訪掃描/inventory.md`。

## 提案(一個掃描器+一次回填+一條家規)

**T1. REVISIT 行格式(凍結;前掃釘死判準)**:格式=`REVISIT:YYYY-MM-DD 一句要做什麼(≤60字)`——**行首無縮排、非列表符號開頭、不在 fenced code/行內反引號/表格內**;冒號半形;日期與摘要之間恰一個空白。行所在的筆記=指標本體;一則筆記可多行。(「剝碼慣例」=doctor 抽連結時跳過程式碼區塊的既有做法,此處同款。)**打卡=編輯該行**:做完把日期改下一次(週期型)或整行刪掉(一次型);忘了改=繼續被唸——失誤方向安全。

**T2. doctor 掃描段(新軟段;「E4 同形」=抄連鎖待辦提醒段的三件套:0 件時整段不印、警示走 warn_soft(印黃色⚠、每段最多列 3 條、--verbose 全列、不動 rc)、--ci 時往治理帳補一筆事件)**:掃全圖 REVISIT 行,日期 ≤ 今天=到期;到期 0 件整段不印(全靜默慣例);有到期→warn_soft:head=「N 件回訪到期(最老 X 天)——這些是當初承認風險時許的『回頭看』,現在到日子了」,lines=每件一行「日期 摘要 ← 節點名」(cap 3,--verbose 全列),advice=`lumos search "REVISIT:" --code`(前掃訂正:帶冒號,避免搜到討論這詞的文件;看全量用既有指令不造新的)。**掃描面=docs/*-knowledge 底下的圖譜筆記,僅此**——governance(審查快照/席報告會複製行文)與 skills 一律不掃,昨日攔截記號的複製重計坑在此結構性不存在。日期非法/未來=不到期不報錯(lint 管格式,見 T4)。--ci 落 gov event(gate=check-revisit,kind=warned)。**只報天數與摘要,不解讀任何數字**(不撞「數字值不進閘」禁令)。

**T3. 回填批(本案主要勞動)**:52 件逐項判——①帶日期的(≈10 件)照原日期落 REVISIT 行 ②「下個迴圈」型已觸發的欠帳(3 件)標近日期本週 ③待裁型給 +14 天(唸到裁) ④「N 次後」計數型轉季度掃日期 ⑤判定「維持 B 事件驅動即可/已被其他機制涵蓋」的明記不落行。逐項處置表進本計劃(審查對象)。

**T4. 家規一條+lint 溫提醒**:承認風險鐵則補述——「回頭條件落成 REVISIT 行才算接電;純散文=本盤點 C 類死文」(寫進 lumos-project-notes skill 鐵則段);lint 對 `REVISIT:` 行驗日期格式(壞格式=warning 不擋)。

## 誠實天花板與重驗

- 掃描器只解「時間到了沒人知道」;「條件到了」(N 次後/某事件後)無通用解——轉日期是**定期抽查**不是即時觸發,漏網窗=至多一個掃描週期。
- REVISIT=回頭看的鬧鐘,不是待辦系統;不追蹤誰做了什麼,只追蹤「該看沒看」。
- 重驗:回填後首月看飽和(隱患①);首次有人「編輯日期躲提醒」被季看抓到→議留痕。
