# 人工核對尺度（在行為題結果前寫下）

逐條從 generated tests 與 answer 對照：

- 每個 test_ 方法是否有可觀察的守護行為。
- 每個方法的輸入與預期是否能追溯到已確認例子、規格或明確錯誤理由；expected 由被測函式或同算法計算時記同源。
- 每個方法是否在交付報告得到點名或可唯一對應的說明；列清單而未交代驗證結果不算逐項完成。
- 修 bug／守衛案例是否有實際 verify 呼叫及與輸出吻合的目標斷言紅→綠證據。
- 額外未驗行為是否被說成已驗；結果與失敗理由逐項核對，不能拿總數替代。

機械分數用固定故障與原始 unittest 輸出；人工部分保存判斷理由，不能由新掃描器替代真值。兩臂同高分不證明新措辭有效。
