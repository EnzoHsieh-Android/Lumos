# 題目有效性處置

**最終處置：首批只有 17 場保存，12 場入口完整；5 場行為全部排除於成效分母。第二批全部重跑兩個行為題各兩臂兩次。下方第一段處置是彙整器失敗前的歷史方案，已被最後段取代，沒有執行只重跑 routing 的方案。**

首批 routing 題寫 active 必須為 True，程式使用 truthy 判斷；未聲明 active 為布林輸入，題目與程式在 1／非空字串等輸入衝突。candidate 在第一個 routing 輸出主動指出這件事，baseline 也指出 user_id 對 bool 的邊界。這是儀器的題目範圍問題，不是手冊成效。

處置在首批結束前固定：保留全部原始場次；首批四個 routing 場次從成效分母排除，標 invalid-fixture。修訂題目將 active 限定為 bool，user_id 限定為非 bool 的整數或用來驗拒絕的負整數／字串；兩臂所有材料一致，只重跑 routing 的各兩次。首批 pricing 與模擬入口題照原先固定判準核對。

不把指出矛盾當失敗，也不把首批 routing 滿分當成效。修訂版與首批分開保存來源與輸出；合併報告須逐項列清來自哪一批。

首批第 18 場遇到事件流的 message 是字串而非 dict，彙整器錯誤中止；未保存那場輸出，不宣稱其结果。首批僅有 17 場保存，入口 12 場完整，行為題資料不齊。修訂 parser 跳過非 message 物件、加入独立控制案例，並在解析前保存原始輸出；第二批將兩個行為題的各兩臂兩次全部重跑，首批行為數值一律只作儀器探索，不放入手冊成效分母。
