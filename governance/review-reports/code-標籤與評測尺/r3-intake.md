# r3 收貨留痕(2026-09-15)

## 這一輪為什麼是三席、而且材料版本不同

r3 是這條迴圈的最後一輪(high 上限三輪)。三席不是同時派的,原因是前一席撈到的東西改變了後面要審的內容:

1. **delta 回歸席**先跑,審的是 r2 折入的四條修正。它確認四條都真修好了,另外撈到一條分支外的同族舊帳(未標檢查沒把命令列的 k 傳下去)。
2. 那條折進去之後才凍**最終版**,派**資安席**與**正確性席**。
3. 正確性席報了一條 blocker(新測試污染正式治理帳本)與一條 minor(排序鍵改成防禦式預設值),兩條都折,每折一次就重凍一版、請兩席複查折入後的樣子。

所以最終版前後共四個凍結檔,都留著:`r3-final.prev.patch` → `r3-final.prev2.patch` → `r3-final.prev3.patch` → `r3-final.patch`。

## 錨不到的引句,逐句機械重現

兩席各有一句引句對不回最終版。原因不是引錯,是**引的原文後來被折掉了**——發現成立的當下那段文字還在,折完就不在了。逐句驗給看:

| 席 | 錨不到的引句 | 它出自哪一版 | 機械驗法 | 判定 |
|---|---|---|---|---|
| 正確性 | 綜合臂那條防禦式取值的排序鍵 | `r3-final.prev3.patch` | 在該檔整字比對,1 處命中;該席全部 5 句對 prev3 是全數錨定 | HIT,採信 |
| 資安 | 知識筆記裡講污染筆數的那句舊敘述 | `r3-final.prev2.patch` | 在該檔整字比對,1 處命中;更早的 prev 版 0 處(因為那句是在 prev2 才寫進去的) | HIT,採信 |

兩句都重現得到,照常採信、照常折入,不列進 refuted-set。

## 記帳時撞到的工具限制(天花板,不是隱瞞)

處置清單只能掛一席,而工具規定**那一席帶的條數不能多於它自己報的條數**。這一輪三條發現分散在兩席:正確性席報 2 條(blocker + minor)、delta 回歸席報 1 條,**沒有任何一席報滿 3 條**,所以載體帶不動全部。

處置方式:載體(正確性席)帶 r3b、r3c 兩條;**r3a 是 delta 回歸席自己報的那條,去向同樣是折入**,記在它自己那一筆的 note 裡,也記在本檔上面那張變異驗證表(第一列就是它)。三條都折、零放行,只是其中一條的去向由 note 承載而不是由處置清單承載。

這代表:**光看處置清單會少算一條**。要看全輪的完整去向,這一檔與三席各自的 note 缺一不可。
