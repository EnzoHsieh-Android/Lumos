**finding 1:審計日期只比到「日」,同一天的舊戳記照樣頂替**
severity: minor
blocking: 否 — 只削弱 r2 G8 新加的順序檢查,不會讓不合格的標記變成合格的;缺口也有補救辦法。
引句:「elif audit_day < max(days):」

- `guard audit --date` 可以填任意日期,所以填一個較晚的日期也能壓過這個檢查。
- 兩邊的日期都用本機時區,機器換時區時可能誤擋,但誤擋時用 `--date` 重審就能解。
