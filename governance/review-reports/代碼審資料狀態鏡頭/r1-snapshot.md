# 代碼審資料狀態鏡頭_計劃

> 白話:代碼審派審查員時,派工詞裡的「正確性」那副眼鏡多加一小段——改動碰到會存下來的資料時,多問七個 DDIA 式的問題(新舊版本讀得懂嗎、寫一半當掉會怎樣、衍生資料取哪一筆、時區對不對……)。不擋推送、作者不用多做事。

## 現況(2026-09-29 讀檔的觀察,以檔案為準)

- 代碼審派工詞的單一來源是 design-loop skill 的派工範本第 3 節:代碼審 reference 的 refute framing 兩處寫「完整鏡頭以範本第 3 節為準」;代碼審 skill 步驟 2 只指到第 3 節的 Codex 做法與圖譜鏡頭格式,沒提正確性鏡頭內容。
- 第 3 節的審查鏡頭有四點:正確性四問(邊界、資源、例外與 None、冪等與併發)、pitfalls manifest、圖譜鏡頭、本案特定鏡頭。沒有新舊互讀、寫一半、衍生資料、時間這幾類。
- 設計審的業務類追問(對外送出、做了回不去)只在審設計稿時出現;直接審程式改動的路徑沒有。本計劃把這兩類併進同一段問句,算是交付 Enzo 那句「設計審追問接到 diff 路徑」——只在審查員鏡頭層,不在 pitfalls 的輸出層。

## 設計

1. 在第 3 節派工詞的「審查鏡頭」清單,第 4 點之後、「錨定紀律」之前,新增第 5 點,文字如下(措辭可再磨,七個子題標頭不改):

```
5. 資料狀態——這份 diff 碰到會被存下來、跨版本讀、或會被別處拿去算的資料時才逐題答;都沒碰到寫一句「不涉及」即可。
   每題也要挑一個具體輸入走一遍(時間題就拿一個具體時刻,例如台北凌晨 1 點＝UTC 的前一天):
   · 新舊互讀:新程式讀舊資料、舊程式讀新資料(新增的紀錄種類、欄位、格式),各會怎樣?
   · 寫一半:寫到一半被中斷(例外、被 kill、磁碟滿),留下什麼狀態?下次讀認得出、救得回嗎?錯誤訊息教的救法真的救得回嗎?
   · 衍生資料:它是真相來源還是算出來的(快取、索引、彙總、狀態提示)?同一件事有多筆紀錄(重跑、重試、撤回)時取哪一筆?
   · 同時讀改寫:兩個行程同時讀出、修改、寫回;或同一次計算讀了兩次、中間被別人改了——結果會不會拼自兩個時間點?
   · 時間:時區不同(UTC 時間戳對本地日期)、時鐘倒退、兩台機器時間不一致時,比大小與判過期還對嗎?
   · 做了回不去:刪除、覆寫、截斷、搬移資料——會不會連帶刪到不該刪的?回滾路徑是什麼?
   · 對外副作用:寄出、推播、扣款、呼叫外部服務寫入——失敗重試會不會重複生效?收端怎麼去重?
```

2. 其他檔不複述這段(單一來源);代碼審 skill 步驟 2 只加半句指路「第 3 節含資料狀態一點」。
3. 新增一支漂移守衛測試:讀範本第 3 節的派工詞圍欄,檢查第 5 點與七個子題標頭都在、而且位於錨定紀律之前;消費專案沒有 skills 目錄時照既有慣例標「沒驗到」。
4. 措辭有兩處是實驗後才調的(時間題附具體時刻、衍生資料題加「多筆紀錄取哪一筆」)——實驗量的是調整前的版本,調整後的效果沒量過。

## 驗收條款

- [S1] 當讀取派工範本第 3 節的代碼審派工詞圍欄,漂移守衛應找到第 5 點資料狀態與七個子題標頭,且第 5 點位於錨定紀律之前 [test:t_data_state_lens_in_code_template]
- [S2] 若第 3 節派工詞缺了七個子題中任一個標頭,守衛的檢查函式應回報缺的是哪一題 [test:t_data_state_lens_missing_item_named]
- [S3] 當編排者照代碼審 skill 步驟 2 派審查員,skill 應在同一步指出第 3 節含資料狀態那一點 [manual:讀代碼審 skill 步驟 2,確認有一句指向範本第 3 節的資料狀態點]

## 回退

退回=刪掉範本第 3 節的第 5 點、代碼審 skill 那半句,以及兩支守衛測試;不碰任何帳本與閘,退回後代碼審派工詞回到原本四點。

## 實務隱患

- 已排除:金流:只改審查員派工詞文字,不碰任何付款流程
- 已排除:對外送出:不寄信、不打外部服務,派工詞只給審查子代理看
- 已排除:不可逆:純文字與測試,刪掉即回原狀,不動帳本
- 已排除:守衛面:不新增、不改任何推送閘或處置閘;新增的漂移守衛只驗範本文字在不在,不擋任何人的推送
- 注意力稀釋:派工詞變長,審查員可能被新題帶離原本會看的地方(實驗案 4 第一次就發生過);所以開頭寫「碰到才答、沒碰到一句帶過」

## 撤除條件

RETIRE-IF:三個月內代碼審席報告裡由第 5 點產出、而且被折入的 finding 少於 3 條;或出現兩次以上「審查員被第 5 點帶離、漏掉通才本來會抓到的洞」的逃逸紀錄

## 誠實界線

- 實驗樣本小(5 個案例、兩案各 3 次),只能說「沒變差、可能稍好」,不能說有效。
- 審查員答了題不等於答對;這段只提高「有人去看」的機率。
