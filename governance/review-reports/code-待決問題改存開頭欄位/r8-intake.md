## 根因分組

1. 清單外鍵名規則(甲):鍵名認法只收「緊貼引號、冒號後空白」一種引號寫法,漏了引號後空白、JSON 風格冒號緊接值、flow 片段裡帶 anchor/tag 的鍵、`-<tab>` 起頭(C1、E2、S1);剝前綴每次切片複製整行,連串 `- ` 變平方級(C4、N3、E3、K3、G3);同一區三份 anchor/alias/tag 偵測(A4);第一輪掃頂格鍵時不再略過頂格註解,`# 備註: x` 把清單切斷(G2);縮排掉的 `pending_questions:` 整份不掃(C7 第三點)。→ 一支前綴走訪函式(索引往前走,認 `- `、`-<tab>`、`? `、anchor、tag)與一支鍵名抽取(引號鍵含跳脫與冒號前空白),清單外規則與結構記號檢查都用它。
2. 看不見的字元(乙):額度上限 8 對真實波斯文、僧伽羅文長句誤擋,絕對上限 16 對 17 個愛心誤擋(C3、E4、G7);私用區與未指派碼位沒有任何限制(C5、E6、S2);軟連字號夾漢字也放行(G7);emoji 表說成「只認 Extended_Pictographic」過頭(K4);額度上限 8、單側 emoji 的 ZWJ、相鄰規則、巢狀 status 豁免、U+1D159、特殊 Zs 計數沒測試釘(C6、K5)。→ 額度改成依可見字數比例、不設固定上限(REVISIT 所說的依樣本調整),私用區與未指派碼位拒讀,軟連字號只在非東亞文字字母間,文件照實寫,補測試。
3. 寫入拒絕與簽核(丙):帶緩衝的檔案把手 truncate 前先 flush,寫滿時截不回而留半行(C2、N1、E1);寫入目標檢查本身丟的 WriteBlocked 不在 except 範圍,筆記不回滾(N2);檢查與 open 之間可換成符號連結(N5);帳檔是目錄時誤報硬連結(G5);第一次簽核失敗留下 0 位元組帳檔(C7 第二點);擋下錯誤三層接法並存、指令內部接住時印原始控制字元(A1、K1、G6、A5);WriteBlocked 定義離使用處遠(A2);寫入拒絕函式說明宣稱唯一(A3)。→ 帳改用不帶緩衝、O_NOFOLLOW 的原始描述子,截回用 ftruncate;寫入目標檢查以 lstat 一次判符號連結、非一般檔、硬連結;WriteBlocked 建立時就清洗訊息,拿掉各分派的重新拋出樣板,main 改成「外殼接、內層 _main 分派」的鄰居寫法;定義搬到寫入原語旁。
4. 決策自由文字與其他(K6、E7、G8、N6、K2、K8、C7 第一點):控制字元與 decided 尾端換行照寫;decision-amend 對換行處理不一致;併發測試用 PIPE 加 wait 可能卡住;文件說「帶註解不算 block scalar」與程式相反、drift 的 dry-run 措辭過度。
