## 收貨

## 處置

- 同輪有 major(合約圖譜 g1、g2),依代碼審規則不放行任何條:27 條全部折入,1 條(c3)列為重現不到。
- 依根因分組統一修(修補與測試見計劃〈審計修正紀錄〉代碼審 r1 與 `r1-fix.json`):
  1. 秒數合不合法與讀檔(c1、c2、e1、e2、e3、a3、a4、p2):執行器與刷新各一支 `_duration_ok`,同一條規則、對照測試守著兩邊一致;都照位元組讀(BOM 也吃)、接住巢狀過深;run 檔讀不懂就略過;舊表讀不懂或有不合法秒數 → rc2 不覆蓋。
  2. 寫檔(k2、s1、a2):刷新改用主程式既有的 `_write_lf`(暫存檔名每次不同、獨佔建檔、失敗自清);寫不進去照慣例「擋下:」。
  3. 表路徑(a1):對照測試守兩邊同一個路徑。
  4. 各片讀到的表一致(k1):每片跑完再讀一次表、跟開頭比,不同就 rc2;不動推送前掛鉤(那邊另一個會談在大改)。
  5. 刷新刪 run 檔(k3):讀的時候記下每個 run 檔的修改時間與大小,刪之前對不上就留著給下次。
  6. CI 腳本(n2、g6、p1):子殼層先 `set +e`、開頭印開始時間。
  7. 效能(e4):份數上限取測試數。
  8. 測試偵測力(g1、g2、g3、g4、g5、c4):分片每條規則一組會翻紅的輸入;壞表形狀補齊;記秒數改在臨時 repo 加會過、紅、例外、逾時、跳過的小測試驗;簿記檔留痕測試的簿記提交加進耗時表。
  9. 其他(n1、g7、e5):補回 return 0 並加行程內回傳值檢查;還原索引用法提示;說明改成「沒給 --repo 又不在 git 專案」。
