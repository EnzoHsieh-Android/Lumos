# 圖譜進迴圈入口栓_計劃

PRIOR-ART: **借用既有原語,不建新機制、不加依賴**——A 用既有 `cmd_search` 多詞回退 + `_rank_score_candidates`(BM25F;★前掃訂正:原寫 `_search_index` 不存在;多詞回退=整串 0 命中自動退 OR 召回,正好接住切詞查詢★)(週考全綠:hook P 0.73-0.80、lift 54-82%(all/train/held 三切面全域;「11 門全過」為同日三筆中的完整切面筆),2026-08-24 帳、之後無新帳)+ `loop next` 既有輸出慣例(比照 `record_cmd`/`scope_cap` 的 advisory 段);B 用同一檢索 + `cmd_new` 既有入口。兩條皆 advisory 不擋,對齊「前置加重一律拒」(不加席不加輪,只把既有資訊端到眼前——同 lint 誠實化、pitfalls 提示的既有形態)。**已排除**:機械相似度硬擋(誤殺合法近名如 v2/std 變體;advisory 即可)、把搜尋接進處置閘(閘語意變更須另案)。

## 問題(兩次真實燒錢事故,非假想)

**這條線=「節點搜尋得到 → 迴圈真的用上」。檢索本身健康**(見 PRIOR-ART 考卷數字),漏在兩個入口:

- **開迴圈不看圖譜**:`loop next` 給輪次/席位/記帳模板,不給「這主題圖譜已有什麼」。★事故:impact 鏡頭案(2026-08-29)開案時 `送審前impact鏡頭機械化_計劃`(已裁 A 案、拒加閘)已存在,搜尋一打就中,但無任何機械點代打——兩輪設計審(十席次)燒完才由外家席發現,案停★(詳 [[Projects/impact鏡頭機械化_計劃]]「我方犯的錯」節)。
- **建節點不查近名**:`cmd_new` **完全同名會擋**(既有五道檢查之一;★前掃訂正:原寫零檢查不實★),但**近名零檢查**——掛點現成(同名檢查之後、mkdir 之前)。★同案:建 `impact鏡頭機械化_計劃` 時近名節點連檔名都撞一半,零警告★。這是重造輪子的最後一道本可攔的門。

## 提案(兩條,全 advisory 不擋)

**A. `loop next` 加「主題既有節點」advisory 段**
- 觸發:每次 `loop next`(文字模式印;--json 加 `related_nodes` 鍵)。
- 查詢詞=迴圈編號去 `code-`/`-std`/`-v2` 等前後綴、按連字號與 CJK 切詞後丟給既有 search。
- 印:前 5 筆命中(格式=節點名+status+決策數;title 完全相同或近名者標 ★近名);零命中印一行「圖譜這主題無既有節點」(誠實,不靜默)。
- 一行指路:「先讀再開;近名者尤其要讀它的 decisions」。

**B. `lumos new` 近名防撞 advisory**
- 建檔**前**:拿新名字切詞搜同型別資料夾;高相似(檔名 difflib 比對 ≥0.6 或 search 前 2 名帶同詞幹)→ 印「★近名節點已存在:○○(status/決策 N 條)——先讀它,確定另開再跑一次★」並**照常建檔**(advisory;不加旗標不加互動,建了但你被告知)。
- 低相似或零命中:靜默照建(不加噪音)。

## 實務隱患(逐類答)

- **效能**:search 對 385 篇實測 0.59s(前掃當場量)(週考在跑同引擎);`loop next` 與 `new` 都是互動指令非熱路徑。已排除。
- **併發/資源/鎖**:純讀索引。已排除。
- **回滾**:兩處各為一段 advisory 輸出,`git revert` 即回,無狀態殘留。
- **不可逆/對外**:不寄送不碰正式環境。已排除。
- **★真隱患:A 的查詢詞切不好=垃圾命中★**——迴圈編號如 `intake-guard`(英文連字)、`圖譜進迴圈入口栓`(CJK 長串)兩型都要切對;CJK 黏成一串幾乎必 0 筆(Landmark 實測家規)。處置:切詞規則進 spec 且測試各給一例;0 筆時印「無既有節點」而非不印(分得出「查了沒有」與「沒查」——lint 空轉教訓)。
- **★真隱患:advisory 被無視(546 前例)★**——誠實承認:這兩條都擋不住不讀。天花板=把資訊送到眼前,讀不讀仍是紀律;但事故形態是「不知道存在」不是「知道了不讀」,送到眼前即命中根因。不做升級計數器(YAGNI;若再發生一次「近名已提示仍重造」再議)。
- **B 誤報(合法近名)**:v2/-std/實作計畫 等變體是日常;advisory 不擋 + 相似門檻收在檔名級,誤報成本=多讀一行。
- **應試化/零依賴**:不涉/已排除。

## 誠實天花板與重驗條件

- 兩條只解「不知道存在」型;「知道了不讀」不在射程。
- **重驗**:上線後下一次「重造輪子」事故若再發生,查當時 A/B 有沒有印、印了為何沒用——印了沒用=升級議題,沒印=切詞 bug。
- A 的 --json 鍵供未來自主迴圈 prompt 消費(它開迴圈也該看),本案不改 orchestrator-prompt(避免多面同動;它的 step 已有 CLAUDE.md 圖譜紀律)。
