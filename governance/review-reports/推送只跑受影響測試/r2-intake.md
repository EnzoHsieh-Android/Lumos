## 先查世界

- PRIOR-ART: 「推上去就跑完整 CI」——GitHub Actions 的 push 觸發可以涵蓋所有分支,以提交編號分組的 concurrency 不會被之後的推送取消(https://docs.github.com/en/actions/writing-workflows/choosing-when-your-workflow-runs/control-the-concurrency-of-workflows-and-jobs);公開 repo 用標準 runner 不計費(https://docs.github.com/en/billing/managing-billing-for-your-products/managing-billing-for-github-actions/about-billing-for-github-actions)。採用:推功能分支即觸發 CI 全套,解掉「沒開 PR 就沒有全套」與「帳本提交取消 PR 的 CI」兩個洞,不需要改 GitHub repo 設定。不採(交使用者):分支保護(會影響所有會談的合併流程,列 Q2)。
