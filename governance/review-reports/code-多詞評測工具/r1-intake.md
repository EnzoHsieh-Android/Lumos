## 錨不到的引句：編排者機械重現

引句一律不動。錨不到的原因有兩種：一種是引句裡含換行或縮排、比對時對不齊；一種是**合約與圖譜那一席引的本來就不是被審的 diff，而是圖譜節點**——那一席的鏡頭就是核對程式跟文件一不一致，所以它的引句該走佐證通道。

重現指令：

```
grep -F "<引句片段>" <該引句真正的出處檔>
```
