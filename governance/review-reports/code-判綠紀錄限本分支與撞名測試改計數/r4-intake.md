## 修前先查世界

- git 的整數設定值可帶 k/m/g 單位字尾、照 C 的 0x 與 0 開頭寫法(git config 文件的整數型別說明;r4 邊界席以 git --type=bool 逐值對照 39 個值實測)。沿用 r3 收貨紀錄的布林規則出處。
- 位址重用:CPython 的 id() 是物件位址,物件釋放後新物件可能拿到同一個位址,所以比 id() 的集合不可靠;改成留住第一份物件再用 is 比(本機實測 L2 改壞下修前的比法照綠)。
