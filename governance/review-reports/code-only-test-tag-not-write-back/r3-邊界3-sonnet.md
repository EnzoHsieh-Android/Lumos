# r3 邊界席(極端輸入)報告

做法:用 importlib 載入 /Users/enzo/harness/lumos-rtb3/scripts/lumos,對 `_nodehome_strip_test_tags` 跑 19 組定向輸入與 30 萬組隨機組合(半形、tab、全形空白、清單符號、核取方塊、空行、標記、中文標點),另跑效能。腳本在 scratchpad 的 fz.py、pf.py。

## 沒找到問題的項目
- 一行多個標記、標記之間沒空白(`a [test:x][test:y] b` 對 `a b`)判同,名稱兩個都進集合要被核對。
- 標記後接中文標點(`a[test:x]，b` 對 `a，b`)判同。
- 連續三個空行夾標記行、文件頭尾是標記行、只有縮排加標記的行,都跟沒標記的版本判同,無多餘或遺漏。
- 清單符號後接全形空白、`- [test:x]x`、`-[test:x]x`:拿掉標記後正文連在一起,跟原文不同,判不同(只會多擋,不會放過)。
- `- [ ]` 單獨一行加標記變成 `- [ ] [test:x]`:判不同,多擋不放過。
- 效能:單行 32000 個標記 0.18 秒、5 萬段多行 0.36 秒、巢狀方括號 2 萬層 0.00 秒,沒有退化。
- Unicode 相似字元(值含西里爾字母等):`_NODEHOME_TEST_TAG_VALUE_RE` 只收 ASCII,不拿掉、留在文字裡造成差異,判不同。

## finding 1
severity: minor
blocking: 否 + 放過的只有「空白有無」這一種內容差,而且必須同時帶一個指得到真測試的新綁定才放行,不能夾帶文字內容變動。
標記前面有正文時連前面空白一起吞,所以「在兩個字之間加一個空白並附一個真綁定」被判成沒變。
引句:「欄位前面有正文就連前面的空白(半形、tab、全形)一起拿掉」
重現(當場可驗):
`S=m._nodehome_strip_test_tags; S("ab")[0] == S("a [test:x]b")[0]` 為真;`S("中文")[0] == S("中 [test:x]文")[0]` 也為真;`S("a\tb")[0] == S("a [test:x]\tb")[0]` 為真。
即英文單字「ab」改成「a b」(兩個字被拆開)、並新增一個真測試綁定,sig_t 一樣,`_nodehome_tag_only_change` 回 True,不算寫說明。
範圍小:只有空白差異,且綁定要真;中文幾乎不受影響,英文單字邊界會受影響。若要嚴格,可在拿掉標記時保留一個空白或比對時把空白分隔差異算進去。這是設計取捨(計劃明定「跟沒寫過那個欄位的同一行一樣」),不是實作錯誤,故降為 minor。

## finding 2
severity: minor
blocking: 否 + 只影響整行只有「核取方塊加綁定」的行,切換勾選狀態與綁定新增同時發生時才放行,內容差僅是勾選。
`_NOTELINES_BARE_LIST_RE` 把 `- [ ]`、`- [x]` 都當「只剩清單符號」,整行丟掉,所以 `- [ ] [test:x]` 改成 `- [x] [test:x]` 前後都被丟,判同。
引句:「拿掉後只剩清單符號或空白的行整行不算」
重現:`S("a\n- [ ] [test:x]\nb")[0] == S("a\n- [x] [test:x]\nb")[0]` 為真(兩邊都丟掉該行);但這需要整行只有核取方塊與綁定,且綁定名稱沒變時根本不核對,所以勾選翻轉會被當成沒變。實際影響:勾選狀態被視為不是內容。
範圍小:行內沒有別的字,只是勾選位元。

## 結論
守衛沒有被繞過去放進文字內容變動;僅兩處屬於「空白或勾選位元」的語意差,都在計劃的設計取捨內,且須有真綁定才放行。

總結:全份最高等級 minor
