## 總結

最嚴重 severity:**blocker**(第 4 條,d3 git diff 波及幅度對最常見的 r1 折入輪無定義,且回代驗證案例本身踩在這個洞上)。
blocking 共 **3** 條(第 1、3、4 條);第 2、5 條已核無 finding。

三條 blocking 都指向同一類問題:spec 對「機械上真的驗得到 / 算得出來」的宣稱,查證後有兩處(refcheck 對佐證通道、git diff 對折入波及幅度)是格式或時序前提不成立才算出「保證」的假象,一處(症狀①雙案同因)是把兩個不同根因的失敗案例講成同一件事。三條都建議在 r1 折入時處理:d1 補「佐證通道強制反引號」或改用 refcheck 認得的格式;d3 補上「r1 折入(無 git 前版)這一輪波及幅度視為不可算,只看結構命中訊號」的分支;症狀①拆成兩條各自對應的獨立摩擦敘述。
