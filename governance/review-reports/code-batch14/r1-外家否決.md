   引句:「open -a "$NOTIFIER" --args "$1" >/dev/null 2>&1 && return 0」  
   why: `open` 的成功只表示 LaunchServices 接受啟動請求，不表示 applet 已執行 `display notification`，更不表示通知中心實際顯示通知。使用者拒絕或關閉此 app 的通知權限時，`open` 仍可回 0，函式立即 `return 0`，第 69–72 行的 `osascript` 退路完全不會執行。這正好留下本批聲稱要補掉的「權限沒開＝靜默不喊」故障；安裝時人工確認一次也不能涵蓋日後被關閉或通知設定重置。核心價值是故障時必須有人知道，因此阻擋合併。
