## F1 「裁定撤除…,理由:改寫…」這種真撤除仍被整段挖掉而漏列(第二輪要修的漏洞換形狀再現)

file: `scripts/lumos:29392`(挖段條件只看「第一個冒號之後」是不是改寫/保留開頭)
1. 輸入(下一層子項一行):`代使用者裁定撤除這條,理由:改寫後的新測試已涵蓋`。
2. _NS_TR_VERDICT_RE 把「裁定撤除這條,理由:」整串當成裁定前綴;冒號後「改寫後…」命中 _NS_TR_KEEP_LEAD_RE,於是 drop 從「裁定」二字挖到行尾,「撤除」被一起吃掉,rest 只剩「代使用者」,回傳 False,該條不列。

4. 這正是 docstring 自稱修掉的「裁定撤除這條,理由:…」形狀;新測試 ⑨ 的理由文字是「展示不再需要」,沒有以改寫/保留/維持開頭,所以沒蓋到。理由欄寫「改寫/維持/保留」很自然。
