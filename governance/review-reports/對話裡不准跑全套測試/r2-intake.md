# r2 收貨(2026-11-08,四席 sonnet 新席:通才、正確性、繞過、架構對齊)

四席報告全數存檔、正規化、引句全錨定(正確性席第一次交回沒有引句,退回補上,內容沒變)。全輪 20 條(blocker 2、major 6、minor 12)。id:tc 通才、co 正確性、bp 繞過、ar 架構對齊,加報告裡的 F 序號。

## 判讀

最重的一群是同一類:「拿旗標或選中支數猜會跑多久」又被打穿——r1 是 `-k t_`,r2 是 `--lf` 被預設切片開成全套(tc1、co1 兩席獨立,blocker)、`--lf` 紀錄過大與過期(co2、bp1)、三成門檻分母不明與分片輪流(co3、bp2、tc2)、文件子集其實四分鐘(bp3)。同類第二輪,照手冊換形狀:對話裡不切片、選完照耗時表估佔比;`--lf` 是 r1 為了解推送前閘提示而新加的機制,r2 指出它自帶四個新洞,拿掉它的最小解是提示改成逐支 `-k`。

## 先查世界

- PRIOR-ART: 依耗時而非支數判斷測試規模——Bazel 測試的 size/timeout 依預期耗時分級(https://bazel.build/reference/test-encyclopedia );本 repo 已有 `_shard_by_duration` 照耗時表分片(表裡沒有的用中位數)。採用:同一份耗時表與同一個權重估法算佔比。
- PRIOR-ART: 理由必填的判法——本 repo `lint-waive --note`(去空白至少 10 字、至少一個文字或數字字元)。採用同一判法,不另寫。
- PRIOR-ART: 家目錄快取寫入——本 repo `scripts/lumos` 的家目錄快取寫入(子目錄、驗目錄可信)。採用。
- 排除:選中支數三成門檻(r1 的做法)——支數與耗時不成比例、分母在分片後失真,r2 兩席打穿。
