# probe輪退場_計劃

> 白話:審查閘過了以後有個「抽查」設計——抽中要再開一輪複驗。這機制上線三週零使用,說明書答應的三個配套(席位可少、不佔輪數、只能一次)程式碼一個都沒做,而它掛靠的那道閘現在只剩歷史帳在用。裁定:抽中不再開輪,判定印出來當觀測;想留它的人要講出理由,沒有人講(Issue 掛牌四天)。

PRIOR-ART:世界=零使用功能退役是通行實務(不另搜);自家先例=①canary 協議停用(2026-08-14 d5:機制退場、判定碼保留供歷史帳回放)②A 案機制碼保留(08-08 code-loop 改處置閘,panel 碼原樣留)③[[Issues/只退場不痛的機制]](零觸發機制的退場判準);裁定=**借用** canary 停用模式:義務退場+碼保留+告示。

## 症狀(會翻紅的證據)

`grep -c '"round": "probe-' docs/.canary-log.jsonl` → 0(機制 2026-08-05 落地至今零執行,[[Issues/probe輪三參數只在散文]] 2026-08-21 實證,本案立案日複驗仍 0)。三參數零實作:cap 計數含全部 distinct round 無 probe 排除、無次數上限、無席數檢查(同 Issue 引 L4 交叉審計 r2 s3 席逐行實證)。宿主閘現況:panel 閘自 d5(2026-08-25,散文審回歸處置閘)與 08-08(code-loop 亦處置閘)後僅供已定錨 panel 帳的舊迴圈回放——「PASS 印應抽查」的觸發面趨近零——抽查印行只存在於 panel 閘兩處(scripts/lumos:4019、4122),處置閘 PASS 無此行(2026-08-25 當日多次 disposal PASS 實測皆無);code-loop SKILL 步驟 7 的義務句因此雙重過期(閘已換、行不再印)。

## 核心裁定

- **d1 退場而非實作**:Issue 兩選項(補實作三參數 vs 退場)取退場——理由:零觸發×宿主閘 legacy×退場成本 0(帳上無 probe 輪要遷);補實作=為一個從未被用過、將來也幾乎無觸發面的機制動收斂閘周邊碼。Issue 原文明標「退場成為預設選項,除非有人講出要留它的理由」——掛牌至今無人講。
- **d2 退場形狀=義務拔除、判定降觀測**(借 canary 停用模式):抽查判定(sha%2 應抽/免抽)的**判定碼與印行保留**(可重算、歷史帳回放可用),PASS 訊息的「應抽查」行追加一句「(觀測;2026-08-25 起不再加開輪)」——一行訊息改,判定謂詞與 panel 兩條合取**一字不動**;skill 散文中「應抽→加開 probe-* 輪」義務與三參數描述刪除。
- **d3 防浮動條款正面處理**:panel「判準凍結」不受本案影響(合取原樣);但條款的「唯一翻案通道=攢滿 20 筆抽查帳」隨 probe 義務退場而失去 feeder,成為死信——本案不偷改該句,**列為待 Enzo 具名認可項**([S3];先例=2026-08-08 Enzo 具名推翻 A 案防浮動條款,見 [[Projects/驗證層去模型化_計劃]]);Enzo 未認可前,convergence-evidence-gate 的 KEY 只加「probe 義務已退場(本案)」的事實句,不動凍結句。
- **d4 probe 冒 major 的撤銷語意保留**:歷史帳回放時若見 probe-* 輪 major,K=2 窗滑入髒輪自然 FAIL 的既有機械語意不動(它不依賴三參數)。
