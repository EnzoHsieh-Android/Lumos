# 首批新題的儀器處置

首批模型會談均有原始事件與生成測試；八場中七場符合 session-valid，shipping repeat1 baseline 在修訂迴圈時嘗試額外 Bash 寫檔被拒絕，依原先規則排除整場。原始事件已保存，不把拒絕歸為測試品質失敗。

多份第一次 verify 回饋前的測試使用正常的有限 for/range 參數化案例，評分器語法子集拒絕它們，故首次生成指標不能從這批推論手冊效果。這是儀器相容範圍問題，不是測試沒抓到故障。

預定處置：保留本批，增加只接受靜態常數 iterable／有限字面值 range 的迴圈支持及獨立控制測試。用新評分器对本批凍結首次測試一致重算，僅作儀器復核；正式效果兩題兩臂各兩次另批全重跑，不能選擇只補失敗臂。本批行為效果全部排除分母。原生路由未用此生成測試評分器，十二場另報，不受重跑影響。

原始最終測試改以 .tests.json 保存完整 code 與 SHA256；不修剪生成內容。
