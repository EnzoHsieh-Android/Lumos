# 原生路由儀器預檢

首場 native-preflight 用 --restricted，init 未列待測 project skill；該場只供儀器診斷，不當 baseline/candidate 路由成效。

第二場 native-preflight-v2 在隔離 git 專案取消 --restricted，保留唯讀 Read/Skill、--setting-sources project、--strict-mcp-config，明示 disableAllHooks、disableBundledSkills、autoMemoryEnabled=false，並關閉三個固定 builtin 的可見度。init 只列 lumos-project-notes，模型實際 Skill invocation 與 handbook Read 都可得。

正式六題两臂固定採第二組參數。技能為臨時專案的最小 body（同一句派讀手冊），手冊兩臂一致，僅 description不同；使用真實原生Skill機制，不宣稱已量測完整安裝版Lumos body、其他技能共存環境或Codex宿主。原始preflight會談與invocation保存且不納正式結果分母。
