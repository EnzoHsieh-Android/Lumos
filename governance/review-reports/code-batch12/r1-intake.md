## 折入(十條全折,放行 0)
1. **兩組關門事件分開認**:設計審那組比對 nodes;code-loop 那組只能從自由文字認編號。
   ★明寫這是啟發式、失效方向偏保守★,並掛回頭條件(正解是讓那支指令收 `--loop` 參數)。
2. **「關門後又記帳」不等於「重開」**:實測過閘後才補記帳是常態(8 分鐘、14 分鐘),
   判準改成超過 24 小時才算重開。★門檻是拍的不是量的★,已寫明並掛回頭條件。
3. **合法 JSON 但不是物件的行**(`[]`、`null`、`42`)會讓整支炸掉——兩個讀取迴圈都補上。
4. **`--exclude ""` 擋下 rc2**:任何字串都以空字串開頭,那會把清單排空而印得像全部結案。
5. **rounds 混用時不吐精確數字**,顯示「混用?」。
6. **新增漂移守衛**:治理帳裡出現過的每一組事件都必須被歸類過(算關門/明確不算),
   而且表裡列的種類都要在真實帳上出現過。★四個沙盤全部驗過翻紅、還原全綠★。
7. **測試 fixture 改成照真寫入端的形狀**,並加一條「過閘後幾分鐘的收尾簿記不算重開」。
8. 免責聲明訂正(兩組的起始日期不同)。
9. 壞行與壞值訊息補成三段式。
10. 補進兩份說明書的速查表與索引。

**結果**:空轉候選從 88 降到 67,其中 code 開頭的從 23 降到 6——
剩下那 6 個查證過是**真的沒有關門紀錄**(治理帳裡完全找不到),不是工具的洞。
