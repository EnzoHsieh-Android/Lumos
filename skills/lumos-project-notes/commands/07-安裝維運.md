# 07 安裝維運(人工操作;Claude 除非被要求,不主動跑)

| 情境 | 指令 | 備註 |
|---|---|---|
| 新機器第一次裝 | `lumos bootstrap`(或 `~/harness/lumos-toolchain/install.sh`) | 裝全域 CLI + skills + 專案接線 |
| 新專案要用圖譜 | `lumos init` | 建資料夾、.gitignore、pre-commit/pre-push |
| 只裝全域指令 | `lumos install [--force]` / 移除 `lumos uninstall` | symlink 到 ~/.local/bin |
| 專案裡的工具組舊了 | `lumos update [--allow-stale]` | 從唯一來源更新;來源拉不到最新會先停。★工具組與 CLAUDE.md、AGENTS.md 的紀律區塊要同一次提交、一起推★:只推工具不推紀律區塊,推送前健康檢查的 [D] 會把「紀律區塊跟範本不同步」算成問題擋下(rtb 2026-10-01 更新 v1.2 時遇到) |
| 「這台機器的 lumos 用哪支 Python?提交為什麼說找不到 3.14?」 | `lumos python-path` | 印一支 Python 3.14 以上的絕對路徑(git 掛鉤就是用它挑直譯器);找不到印說明與安裝指令回 2。舊版 `python3` 叫它也行,會自己改用 3.14;`LUMOS_PYTHON` 有設就只認它 |
| 專案不用了 | `lumos deinit`(只拆專案層) / `lumos teardown`(連機器全域一起拆,圖譜保留) | 非互動要加 --yes |
| 把 sqlfluff / stylelint / dart analyze 輸出接進 lint 適配器 | `sqlfluff … --format json \| lumos sqlfluff-sarif`;`stylelint … --formatter json \| lumos stylelint-sarif`;`dart analyze --format=json … \| lumos dart-sarif`(讀不懂 rc2、不吐空結果) | 轉 SARIF |
