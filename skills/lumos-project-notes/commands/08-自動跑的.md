# 08 自動跑的(hook 會替你呼叫,不用手敲;但要看得懂它印什麼)

| 時機 | 自動跑什麼 | 擋不擋 |
|---|---|---|
| `git commit` 前(pre-commit) | 污染檢查、`lumos lint` 逐篇、`lumos home check --staged`(每支檔有家;「該動哪篇」的點名也在這裡照家算)、`lumos note-shape --staged`(筆記形狀擋;另印否定現況句提醒,不擋)、「改 code 沒動圖譜」檢查、`lumos cochange check`、`lumos delguard` | 前四項擋;後兩項提醒 |
| `git commit` 後(post-commit) | 記 bypass 帳(用 --no-verify 繞過也會留痕) | 不擋 |
| `git push` 前(pre-push) | `lumos anchor verify`、全套測試、`lumos home check --diff`(每支檔有家,這次要推的範圍整段查一次)、`lumos note-shape --diff`(筆記形狀擋,同一段範圍)、`lumos code-loop check`(每個分支 ref 無條件叫;合約測試紅 / 效能檢核題沒表態 / 高風險沒審查留痕,三個判定各自擋)、`lumos drift check --diff <遠端舊值>..<頂端> --push-remote <遠端> --pushed-ref <ref>`(存量漂移檢查,分支與 tag 都查;同一次也跑舊句檢查 m1:這次消失的程式名稱筆記還在講的句子,開關另一個 `drift_check.old_sentence`,有改到程式檔就一定印一行結論、記一筆帳;起點由工具算:所有主線候選(遠端 HEAD、main/master 的 upstream、遠端 main/master,跳過就是這次推的那條)一起取離頂端最近的分岔點,跟遠端舊值取比較新的;兩個參數要一起給)、`lumos doctor --ci` | 全擋;★drift check 例外★:c1 到 c5 與回頭條件沒寫設定就擋(2026-09-30 起預設 block),`.lumos/config.json` 的 `drift_check.gate` 設 warn 只印、設 off 關掉;舊句檢查另一個開關 `drift_check.old_sentence`,沒寫是 warn 只印、設 block 才擋、設 off 關掉,跟 gate 各管各的;單次略過 `LUMOS_SKIP_DRIFT_CHECK=1`(兩種一起略過、留帳);舊句檢查擋下時要改的是 `drift_check.old_sentence`,改 gate 沒用;舊句檢查自己出錯(內部例外、時間到、git 讀不出)算判不了:old_sentence=warn 講一句、回 0 放行,block 回 1 擋;其他工具沒跑成(錯誤、git 太慢)講一句就放行(被 Ctrl-C 等訊號中斷、回傳碼 128 以上則停下,其他閘也一樣) |
| `git push` 前(pre-push,低風險那一路) | 同一次 `code-loop check` 帶 `--bound-tests-advisory`:這次改動碰到的硬合約綁的測試紅了只印 | ★合約測試只提醒不擋★(人裁 2026-09-07);表態閘照擋(不看 tier,2026-09-09) |
| CI(push 後) | 同 pre-push + `lumos code-loop check`、`lumos drift check`(補查 --no-verify 繞過的;drift 那步先照預設分支補 origin/HEAD(actions/checkout 不建),再交 before..sha 加 `--push-remote origin --pushed-ref "$GITHUB_REF"`,起點跟推送前同一支算) | 紅燈(drift check 沒寫設定就是 block;設了 warn 不紅;工具出錯照紅,但舊句檢查自己出錯時照它的開關:old_sentence=warn 不紅、block 紅) |
| Claude 要 Edit/Write 前(impact hook) | `lumos impact --file <檔>` 的結果注入 | 只提醒;邊界仍要自己查 |
| 回合結束(check-graph-sync,Stop hook) | 提醒「改了 code 還沒動圖譜」 | 兩家同 session 擋一次續做(`LUMOS_STOP_BLOCK_OFF=1` 關;2026-09-05 起 Claude 也擋) |
| 每天 09:30(autonomous-loop) | 自動選題 → 設計審查 → 備 pending 等人放行 | — |
| 每天 09:30(launchd daily-governance) | 治理日報、lint-watch 版本掃、doctor --ci、testmap 重建、每週回放與探針抽查;★自主迭代 loop 的派工 2026-09-05 起暫停(LUMOS_AUTOLOOP_OFF 預設 1)★ | 全 fail-open;腳本已包成 main() 免邊跑邊改讀到半行 |

看到「擋下:」就是上面某一道擋了,訊息第一句講發生什麼、最後一行給該敲的指令。
